# v0.8.0 — DCM for Evoked Responses (EEG/MEG ERP) — SCOPE PROPOSAL

**Status:** PROPOSAL (authored 2026-06-25 from the actinf_physics side; formalize with `/gsd:new-milestone` in this repo). Not committed — review first.
**Slots after:** v0.7.0 Variational Laplace Validation (Phases 29-32). Next phases = 33+.

---

## 0. Why

Pyro-DCM today is an **fMRI / spectral DCM**: bilinear neural state (`neural_state.py`) → Balloon-Windkessel (`balloon_model.py`) → BOLD, plus spectral/CSD (`spectral_transfer.py`, `mar_csd.py`, SPM12-compatible). There is **no time-domain evoked-response (ERP) capability** — no neural-mass generative model, no evoked integration, no M/EEG lead-field. A grep for `jansen|neural_mass|spm_fx_erp|evoked` returns nothing in `src/`.

This milestone adds **DCM for Evoked Responses** — the neural-mass + evoked + lead-field stack — so Pyro-DCM can generate **time-domain scalp ERPs (MMN/P300)**, SPM12-parity validated.

**Downstream consumer:** the `actinf_physics` repo (Phase 133 / NEURO2-04, currently deferred) will feed its hierarchical precision + connectivity parameters into this model to produce **forward psychosis-MMN predictions** (reduced sensory/prior precision → attenuated MMN/P300; the Adams 2013 / Ranlund 2016 reduced-rIFG-self-inhibition result). That use case is forward-only (no fitting) and motivates the **canonical-microcircuit (CMC)** choice below.

## 1. Model choice (decide in Phase 33)
Two SPM neural-mass families generate ERPs:
- **ERP / Jansen-Rit** (`spm_fx_erp.m`) — 3 populations (pyramidal, excitatory + inhibitory interneurons); the classic DCM-ERP.
- **Canonical microcircuit (CMC)** (`spm_fx_cmc.m`) — 4 laminar populations (superficial pyramidal, spiny stellate, inhibitory interneurons, deep pyramidal); maps precision → **superficial-pyramidal self-inhibition (gain)**.
**RECOMMENDED: CMC.** The downstream psychosis use case is precisely about *precision = superficial-pyramidal gain* and *rIFG self-inhibition* (Adams/Ranlund) — CMC exposes exactly that parameter, ERP does not. Confirm in Phase 33.

## 2. Phases (v0.8.0)

### Phase 33 — Neural-mass forward model (single source), SPM12-parity
- Implement the CMC (or ERP) population ODE in PyTorch: state derivatives `dx/dt = f(x, u, θ)` with the convolution (He/τ) kernels + sigmoid firing; SPM12 parameter conventions (mirror the `parameterize_A` / `-exp(...)` transforms already used in `neural_state.py`).
- **SPM12 parity gate:** single-source dynamics match `spm_fx_cmc.m`/`spm_fx_erp.m` on frozen fixtures (the Phase-32 cross-validation pattern; `../spm12` as ground truth).
- Deliverable: `forward_models/neural_mass_erp.py` + parity tests.

### Phase 34 — Extrinsic coupling + evoked integration (multi-source)
- Extrinsic **forward / backward / lateral** connections (A matrices) + condition-specific modulation (B) + input (C) wired into the neural-mass network; intrinsic gains per source.
- **Evoked integration:** integrate the coupled system under a stimulus input over a peristimulus window → per-source LFP timeseries (the `spm_gen_erp.m` analog). Reuse the ODE integrator conventions from `coupled_system.py`.
- **SPM12 parity gate:** multi-source evoked response matches `spm_gen_erp` for a reference A/B/C.
- Deliverable: the evoked generator + parity fixtures.

### Phase 35 — Spatial/lead-field observation → scalp ERP
- Lead-field / gain matrix projecting source activity (pyramidal depolarization) → sensors (the `spm_lx_erp.m` / spatial-model analog). For forward prediction a simple lead-field (or single-dipole-per-source) suffices; full sensor montage optional.
- Output: **scalp ERP waveform** (time × sensors), incl. the deviant−standard **difference wave** (MMN/P300).
- **SPM12 parity gate:** end-to-end source→scalp matches an SPM DCM-ERP forward run.
- Deliverable: `forward_models/erp_observation.py` + the scalp-ERP forward.

### Phase 36 — ERP-DCM model class + inference + MMN demo
- An `models/erp_dcm_model.py` wrapping forward + priors (A/B/C, intrinsic gains, kernels) in the Pyro idiom, consistent with `spectral_dcm_model.py`; wire into the **VL** (v0.7.0) and amortized inference paths.
- **MMN/oddball forward demo:** a standard-vs-deviant paradigm; sweep the **superficial-pyramidal gain / self-inhibition** (the precision parameter) and show **attenuated MMN** — the Adams/Ranlund psychosis signature. This is the artifact `actinf_physics` consumes.
- Deliverable: the model class + the MMN demo + 1-2 figures.

## 3. Conventions (match the existing repo)
- SPM12-parity via frozen fixtures at every phase (Phase-32 pattern); `../spm12` as reference.
- `[REF-xxx]` citation style; SPM-convention parameter transforms; bit-exact backward compatibility for existing fMRI/spectral paths (additive only).
- VL + amortized inference reuse (v0.7.0 stack).

## 4. Out of scope / notes
- Real M/EEG *data fitting* on empirical ERPs — this milestone is the **forward + parity** capability; fitting can follow once the forward is validated.
- The actinf psychosis-MMN application lives in `actinf_physics` (it imports this model); keep this milestone domain-agnostic (a general DCM-ERP), not physics-task-specific.
- Effort: ~4 phases, comparable to v0.3.0 (Bilinear) / v0.6.0 (Latent Circuit). The neural-mass ODE (Phase 33) + the SPM parity gates are the bulk.

## 5. Hand-off to actinf_physics
Once v0.8.0 ships, `actinf_physics` Phase 133 / NEURO2-04 becomes a thin **adapter**: map its `(pi_v, pi_w, w_topdown, foveal)` → CMC intrinsic gains + extrinsic A/B/C → this model's forward → scalp MMN/P300, reproducing the precision-attenuated MMN. No new data; forward-only.
