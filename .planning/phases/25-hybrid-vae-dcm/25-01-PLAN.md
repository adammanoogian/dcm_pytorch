<objective>
Create the two foundational primitives for the hybrid VAE-DCM: (1) a parameter
packer that includes initial conditions x0 alongside A_free, C, and noise_prec,
and (2) an encoder network that maps observed timeseries to approximate posterior
parameters (z_loc, z_scale) for the packed DCM parameter vector.

Purpose: These primitives are the building blocks for Plan 02's Pyro model/guide
pair. The packer defines the latent space structure; the encoder provides the
recognition network that amortizes inference.

Output: LatentCircuitDCMPacker class in parameter_packing.py, DCMEncoderNet class
in dcm_encoder_net.py, unit tests proving round-trip correctness and shape contracts.
</objective>

   SpectralDCMPacker). Follow the exact same interface as TaskDCMPacker:
   - `__init__(self, n_regions, n_inputs, a_mask, c_mask)` — same params as
     TaskDCMPacker, but `n_features = N*N + N*M + N + 1` (adds N for x0).
   - `pack(params)` — packs dict with keys "A_free" (N,N), "C" (N,M),
     "x0" (N,), "noise_prec" (scalar positive). Ordering:
     `[A_free.flatten(), C.flatten(), x0, log(noise_prec)]`.
     Log-space contract for noise_prec (same as TaskDCMPacker).
     Refuse bilinear keys with NotImplementedError (same pattern as TaskDCMPacker.pack).
   - `unpack(z)` — reverse of pack, supports batch dims via `z.shape[:-1]`.
     Returns dict with "A_free" (N,N), "C" (N,M), "x0" (N,), "noise_prec" (scalar, log-space).
   - `fit_standardization(dataset)` — identical pattern to TaskDCMPacker.
   - `standardize(z)` / `unstandardize(z_std)` — identical pattern.
   - NumPy-style docstring with `from __future__ import annotations`.

2. Create `src/pyro_dcm/guides/dcm_encoder_net.py` with `DCMEncoderNet(nn.Module)`:
   - `__init__(self, n_regions, n_features, embed_dim=256)`:
     - 3-layer 1D-CNN backbone: Conv1d(n_regions, 64, k=5, pad=2) + BN + ELU,
       Conv1d(64, 128, k=5, pad=2) + BN + ELU, Conv1d(128, embed_dim, k=5, pad=2)
       + BN + ELU. Use ELU not ReLU (smooth activation for adjoint ODE backprop
       compatibility, see 25-RESEARCH.md Pitfall 5).
     - AdaptiveAvgPool1d(1) to collapse temporal dimension.
     - Two output heads: `fc_loc = nn.Linear(embed_dim, n_features)` and
       `fc_scale = nn.Linear(embed_dim, n_features)`.
     - Initialize fc_loc weights and bias to zeros (near-prior-mean output,
       Pitfall 1 mitigation).
     - Initialize fc_scale bias to -2.0 (softplus(-2) ~ 0.13, conservative
       initial posterior width).
     - Call `self.double()` for float64 (project convention).
   - `forward(self, x)`:
     - Input shape (T, N) unbatched or (batch, T, N) batched.
     - Handle unbatched by unsqueezing dim 0.
     - Transpose to (batch, N, T) for Conv1d.
     - Pass through CNN backbone + pool + squeeze.
     - z_loc = fc_loc(x), z_scale = F.softplus(fc_scale(x)) + 1e-5.
     - If unbatched, squeeze batch dim from both outputs.
     - Return tuple (z_loc, z_scale).
   - Full NumPy-style docstring citing 25-RESEARCH.md.

3. Update `src/pyro_dcm/guides/__init__.py`:

   - Add import for `DCMEncoderNet` from dcm_encoder_net.
