**1. Enhance `scripts/train_hybrid_vae_dcm.py`:**

Add to the existing training script:
- `--save_encoder` flag (default True) — saves encoder state_dict, packer
  standardization (mean_, std_), and training config to output_dir.
- `--save_recovery_report` flag (default True) — after training, evaluate on
  50 held-out test examples and save a JSON report with:
  - Per-example: A_free_rmse, A_sign_recovery, C_rmse, x0_rmse.
  - Aggregated: mean/std of each metric.
  - Inference timing: mean time per forward pass (should be < 1s).
  - KL divergence: final epoch average (should be > 0.1, not collapsed).
- `--n_test` (default 50) — number of held-out test examples.
- After training, print a summary table with recovery metrics.
- Save training loss curve as PNG (matplotlib).

**2. Create `cluster/sbatch_hybrid_vae_dcm.sh`:**

Follow existing cluster sbatch patterns (see cluster/ directory for examples).
```bash
#!/bin/bash
#SBATCH --job-name=hvae_dcm_train
#SBATCH --partition=comp
#SBATCH --nodes=1
#SBATCH --ntasks=1
#SBATCH --cpus-per-task=4
#SBATCH --mem=16G
#SBATCH --time=04:00:00
#SBATCH --output=cluster/logs/hvae_dcm_%j.out
#SBATCH --error=cluster/logs/hvae_dcm_%j.err

module load python/3.10
source $HOME/.venvs/dcm/bin/activate

python scripts/train_hybrid_vae_dcm.py \
    --n_samples 1000 \
    --n_epochs 200 \
    --warmup_epochs 40 \
    --n_regions 4 \
    --n_inputs 1 \
    --duration 5.0 \
    --dt 0.01 \
    --lr 1e-3 \
    --seed 42 \
    --n_test 50 \
    --output_dir results/hybrid_vae_dcm
```

Estimated runtime: ~2-3 hours for 1000 examples x 200 epochs on CPU.

**3. Create `tests/test_hybrid_vae_dcm_recovery.py`:**

Tests that load a trained encoder and validate recovery quality. These tests
are designed to be run AFTER the cluster training job completes.

Use `@pytest.mark.slow` marker so they can be skipped in fast CI runs.

1. `test_load_trained_encoder` — Load encoder state_dict and packer stats
   from `results/hybrid_vae_dcm/`. Assert encoder produces valid outputs.
   Skip if checkpoint not found.
2. `test_recovery_a_rmse_below_threshold` — Load recovery report JSON.
   Assert mean A_free RMSE < 0.3 across test examples. Skip if report
   not found.
3. `test_recovery_sign_accuracy_above_chance` — Assert mean A_free sign
   recovery > 0.6 (above chance=0.5 by a meaningful margin).
4. `test_amortized_inference_timing` — Assert mean inference time < 1.0
   second per example.
5. `test_kl_not_collapsed` — Assert final KL divergence > 0.1 (no
   posterior collapse, Pitfall 2 check).

All tests use `pytest.importorskip` or `skipif` patterns for the checkpoint.
