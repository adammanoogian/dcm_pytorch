<objective>
Build the core Pyro model/guide pair for the hybrid VAE-DCM. The model function
uses the DCM forward model (CoupledDCMSystem with hemodynamic=False) as the
decoder, sampling a packed latent vector from a standard normal prior and
deterministically decoding it into predicted trajectories. The guide class wraps
DCMEncoderNet as a recognition network that maps observed trajectories to an
approximate posterior over the packed DCM parameters.

Purpose: This is the central architecture of Phase 25 -- a physics-informed VAE
where the decoder embeds known dynamical systems equations (bilinear neural state
ODE), making the latent space interpretable as DCM connectivity parameters.

Output: `hybrid_vae_dcm_model` function + `HybridVAEDCMGuide` class in
`src/pyro_dcm/models/hybrid_vae_dcm.py`, with integration tests proving the
model/guide pair works with Pyro SVI.
</objective>

**1. `hybrid_vae_dcm_model` function (the decoder/generative model):**

```
def hybrid_vae_dcm_model(
    observed_trajectories: torch.Tensor,
    stimulus: object,
    a_mask: torch.Tensor,
    c_mask: torch.Tensor,
    t_eval: torch.Tensor,
    dt: float,
    packer: LatentCircuitDCMPacker,
) -> None:
```

Implementation:
- Sample `_latent` from `dist.Normal(zeros(n), ones(n)).to_event(1)` where
  `n = packer.n_features`. This is the standard normal prior in standardized
  space (same pattern as `_sample_latent_and_unpack` in amortized_wrappers.py).
- Unstandardize via `packer.unstandardize(z_std)`.
- Unpack via `packer.unpack(z)` to get A_free, C, x0, noise_prec.
- Apply masks: `A_free = A_free * a_mask`, `C = C * c_mask`.
- `A = parameterize_A(A_free)` — deterministic site "A".
- `noise_prec = noise_prec.exp()` — log-space contract.
- Build `CoupledDCMSystem(A, C, stimulus_fn, hemodynamic=False)` where
  stimulus is converted to PiecewiseConstantInput if dict.
- `solution = integrate_ode(system, x0, t_eval, method="rk4", step_size=dt)`.
  NOTE: x0 comes from the latent, NOT zeros. This is the key difference from
  latent_circuit_dcm_model.
- `predicted_trajectories = solution[:T]` where T = observed_trajectories.shape[0].
- NaN guard: if any NaN/Inf, replace with `torch.zeros_like(...).detach()`.
- `pyro.deterministic("predicted_trajectories", predicted_trajectories)`.
- `C_obs = torch.eye(N)`, apply `direct_observation(predicted_trajectories, C_obs, noise_prec)`.
- `pyro.sample("obs", dist.Normal(y_mean, noise_std).to_event(2), obs=observed_trajectories)`.

NumPy-style docstring citing [REF-001] Eq. 1 and 25-RESEARCH.md.
Module docstring explaining the hybrid VAE-DCM architecture.

**2. `HybridVAEDCMGuide(nn.Module)` class (the encoder/recognition network):**

```
class HybridVAEDCMGuide(nn.Module):
    def __init__(self, encoder_net: DCMEncoderNet, packer: LatentCircuitDCMPacker):
```

- Store encoder_net and packer as attributes.
- `forward(self, observed_trajectories, *args, **kwargs)`:
  - `pyro.module("hybrid_vae_dcm_encoder", self.encoder_net)`.
  - `z_loc, z_scale = self.encoder_net(observed_trajectories)`.
  - `z_std = pyro.sample("_latent", dist.Normal(z_loc, z_scale).to_event(1))`.
  - Return z_std.
- `sample_posterior(self, observed_trajectories, n_samples=1000)`:
  - eval mode, no_grad.
  - Get z_loc, z_scale from encoder.
  - Sample `z_std = dist.Normal(z_loc, z_scale).sample((n_samples,))`.
  - Unstandardize and unpack via packer.
  - Return dict of parameter samples.
  NumPy-style docstring.
