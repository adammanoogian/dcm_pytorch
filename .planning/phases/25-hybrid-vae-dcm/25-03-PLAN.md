<objective>
Build the training infrastructure for the hybrid VAE-DCM: (1) a synthetic dataset
generator that creates diverse DCM parameter sets and simulates trajectories,
(2) a training loop with KL annealing for stable ODE decoder training, and (3) a
training script usable locally for smoke tests and on the M3 cluster for full runs.

Purpose: The training loop is where the encoder learns to map observations to DCM
parameters. KL annealing is mandatory for ODE-based decoders (research Pitfall 1/2)
to prevent early-training divergence and posterior collapse. The synthetic dataset
provides ground truth for validating recovery quality.

Output: `train_hybrid_vae_dcm` and `generate_synthetic_vae_dataset` functions,
training script `scripts/train_hybrid_vae_dcm.py`, integration tests.
</objective>

**1. `generate_synthetic_vae_dataset` function:**

```
def generate_synthetic_vae_dataset(
    n_samples: int,
    n_regions: int = 4,
    n_inputs: int = 1,
    duration: float = 5.0,
    dt: float = 0.01,
    seed: int = 42,
) -> list[dict[str, torch.Tensor]]:
```

For each sample:
- Generate random A via `make_stable_latent_circuit_A(n_regions, seed=seed+i)`.
- Generate random C: sample from N(0, 0.5), mask with ones(N, M).
- Generate random x0: sample from N(0, 0.1) -- small initial perturbations.
- Generate random noise_prec: sample from Uniform(5, 50).
- Create a simple block stimulus (on at t=1-2s, off otherwise) via
  `PiecewiseConstantInput`.
- Simulate trajectory via `simulate_latent_circuit(A, C, stimulus, ..., dt=dt,
  duration=duration)`.
- Add Gaussian noise to trajectory with std = 1/sqrt(noise_prec).
- Store dict: {"observed": noisy_trajectory, "A": A, "C": C, "x0": x0,
  "noise_prec": noise_prec, "stimulus": stimulus, "t_eval": t_eval,
  "a_mask": ones(N,N), "c_mask": ones(N,M)}.

Return list of dicts. All tensors dtype float64.

**2. `train_hybrid_vae_dcm` function:**

```
def train_hybrid_vae_dcm(
    model_fn: callable,
    guide: HybridVAEDCMGuide,
    train_data: list[dict],
    n_epochs: int = 100,
    warmup_epochs: int = 20,
    lr: float = 1e-3,
    clip_norm: float = 10.0,
    log_every: int = 10,
) -> dict[str, list[float]]:
```

Implementation:
- Create `pyro.optim.ClippedAdam({"lr": lr, "clip_norm": clip_norm})`.
- Create `pyro.infer.SVI(model_fn, guide, optimizer, loss=pyro.infer.Trace_ELBO())`.
- For KL annealing: wrap the model call with `pyro.poutine.scale` using
  `scale=beta` where `beta = min(1.0, epoch / max(1, warmup_epochs))`.
  Implement this by creating a `_scaled_model` closure that applies
  `pyro.poutine.scale(scale=beta)` context manager around the model call.
  The `_latent` site's KL is the only KL term (model has N(0,I) prior,
  guide has N(z_loc, z_scale)). Scaling the entire model scales both the
  likelihood and the prior, but this is the standard Pyro approach for
  beta-VAE / KL annealing -- it is equivalent to scaling just the KL when
  the likelihood weight is fixed at 1.

  CORRECTION: For proper KL annealing, we want to scale ONLY the KL
  contribution, not the likelihood. In Pyro, this is done by scaling
  the `_latent` sample site in the MODEL only. Use:
  ```
  def scaled_model(beta, *args, **kwargs):
      def _model(*a, **kw):
          with pyro.poutine.scale(scale=beta):
              z = pyro.sample("_latent", prior_dist)
          # ... rest of model without scale ...
      return _model
  ```
  BUT this is complex to implement cleanly. The simpler standard approach
  (used in the Pyro VAE tutorial) is to scale the ENTIRE model by beta
  for the warmup period. This is acceptable because during warmup (beta<1)
  the reduced likelihood weight simply makes training more conservative.

  USE THE SIMPLE APPROACH: Scale the entire model call by beta. This is
  the standard Pyro KL annealing pattern.

- Training loop: for each epoch, shuffle train_data, iterate over examples.
  For each example, call `svi.step(observed_trajectories=ex["observed"],
  stimulus=ex["stimulus"], a_mask=ex["a_mask"], c_mask=ex["c_mask"],
  t_eval=ex["t_eval"], dt=dt, packer=guide.packer)`.
- Track: epoch_losses, reconstruction_losses (if separable).
- Log progress every `log_every` epochs.
- Return dict: {"losses": epoch_losses, "betas": beta_schedule}.

NumPy-style docstrings for both functions.

Also update __init__.py imports to include the new functions if needed.

  sign(A_free_predicted) == sign(A_true_free)).
- Saves: training losses plot (matplotlib), encoder state_dict, packer
  standardization stats, recovery summary.
