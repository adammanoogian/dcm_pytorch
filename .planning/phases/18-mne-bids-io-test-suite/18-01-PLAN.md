    ```python
    from __future__ import annotations

    from unittest.mock import MagicMock

    import numpy as np
    import pytest
    import torch

    mne = pytest.importorskip("mne")

    from pyro_dcm.io.mne_loader import (

        epochs_to_timeseries,
        raw_to_timeseries,
        stc_to_roi_timeseries,
    )

    pytestmark = pytest.mark.mne
    ```

    **Fixtures** (local to this file, NOT in conftest.py since they need MNE):

    1. `synthetic_epochs` fixture: 10 epochs, 3 EEG channels ("EEG1", "EEG2", "EEG3"), 256 Hz, 1.0s duration. Random data * 1e-6 (Volts). seed=42.

    2. `synthetic_raw` fixture: 3 EEG channels ("EEG1", "EEG2", "EEG3"), 256 Hz, 10 seconds. Random data * 1e-6 (Volts). seed=42.

    3. `sine_epochs` fixture: FOR CSD SINE INJECTION TEST. 20 epochs, 2 EEG channels ("EEG1", "EEG2"), 256 Hz, 2.0s per epoch. Both channels contain a 10 Hz sine wave + small noise (0.01 * randn). Data * 1e-6 (Volts). seed=42.

    **Tests:**

    TEST-01: `test_epochs_to_csd_shape`
    - Call epochs_to_csd(synthetic_epochs, fmin=1.0, fmax=50.0, n_freqs=32)
    - Assert result["csd"].shape == (32, 3, 3)
    - Assert result["csd"].is_complex()
    - Assert result["freqs"].shape == (32,)
    - Assert len(result["ch_names"]) == 3
    - Assert result["sfreq"] == 256.0
    - Assert result["n_epochs"] == 10

    TEST-02: `test_epochs_to_timeseries_shape_averaged` and `test_epochs_to_timeseries_shape_unaveraged`
    - Averaged: epochs_to_timeseries(synthetic_epochs, average=True)
      - Assert result["timeseries"].shape == (256, 3) — (T=sfreq*duration, N=3)
      - Assert result["timeseries"].dtype == torch.float64
    - Unaveraged: epochs_to_timeseries(synthetic_epochs, average=False)
      - Assert result["timeseries"].shape == (10, 256, 3) — (n_epochs, T, N)
      - Assert result["timeseries"].dtype == torch.float64
    - Both: Assert result["times"].shape == (256,) and len(result["ch_names"]) == 3

    TEST-03: `test_raw_to_timeseries_shape`
    - Call raw_to_timeseries(synthetic_raw)
    - Assert result["timeseries"].shape == (2560, 3) — (T=10*256, N=3)
    - Assert result["timeseries"].dtype == torch.float64
    - Assert result["times"].shape == (2560,)
    - Assert len(result["ch_names"]) == 3
    - Assert result["sfreq"] == 256.0

    TEST-04: `test_stc_to_roi_timeseries_shape`
    - Create mock SourceEstimate with times = np.linspace(0, 1, 100) and tstep = 1/256
    - Create 3 mock labels. CRITICAL: set label.name = f"ROI_{i}" as separate attribute assignment (NOT via MagicMock(name=...) which sets repr name).
    - Create mock src.
    - Use monkeypatch.setattr(mne, "extract_label_time_course", mock_fn) where mock_fn returns np.random.default_rng(42).standard_normal((3, 100)) array.
    - Call stc_to_roi_timeseries(mock_stc, mock_labels, mock_src)
    - Assert result["timeseries"].shape == (100, 3)
    - Assert result["timeseries"].dtype == torch.float64
    - Assert result["times"].shape == (100,)
    - Assert result["roi_names"] == ["ROI_0", "ROI_1", "ROI_2"]
    - Assert result["sfreq"] == 256.0

    TEST-05: `test_channel_picks_subsetting`
    - Create 5-channel synthetic epochs ("EEG1" through "EEG5", 5 epochs, 256 Hz, 1s)
    - Call epochs_to_timeseries with picks=["EEG1", "EEG3"] (explicit name list)
    - Assert result["timeseries"].shape[1] == 2 (N=2, not 5)
    - Assert result["ch_names"] == ["EEG1", "EEG3"]
    - Also test raw_to_timeseries with picks=["EEG2"] on a 5-channel raw
    - Assert result["timeseries"].shape[1] == 1

    TEST-06: `test_bad_channel_exclusion`
    - Create 3-channel synthetic epochs
    - Mark "EEG2" as bad: epochs.info["bads"] = ["EEG2"]
    - Call epochs_to_timeseries with picks=None (default)
    - IMPORTANT: The loader does NOT auto-exclude bads when picks=None because it uses `epochs.copy().pick(picks) if picks is not None else epochs` — with picks=None it passes epochs through unchanged. Then epochs.average() produces Evoked with ALL channels including bads.
    - So with picks=None: result["timeseries"].shape[1] == 3 (bads NOT excluded)
    - With picks="eeg" (type string): The loader does epochs.copy().pick("eeg"), and pick() uses exclude=() by default, so bads are KEPT.
    - Actually, test the behavior the loader actually produces. Read the loader code carefully:
      - picks=None: no subsetting, all 3 channels including bad.
      - picks="eeg": epochs.copy().pick("eeg") — pick() with exclude=() keeps bads, so still 3 channels.
    - To properly exclude bads, user must use picks explicitly without the bad channel.
    - Test: with info["bads"] = ["EEG2"] and picks=["EEG1", "EEG3"], output has 2 channels.
    - This test documents the P3 pitfall behavior explicitly.

    TEST-07: `test_csd_hermitian_symmetry`
    - Call epochs_to_csd(synthetic_epochs, fmin=1.0, fmax=50.0, n_freqs=32)
    - csd = result["csd"] — shape (F, N, N)
    - Assert torch.allclose(csd, csd.conj().transpose(-2, -1), atol=1e-10)

    TEST-08: `test_csd_nonnegative_autospectra`
    - Same CSD as TEST-07
    - For each channel i: assert csd[:, i, i].real >= -1e-12 (all auto-spectra non-negative)
    - For each channel i: assert torch.allclose(csd[:, i, i].imag, torch.zeros_like(csd[:, i, i].imag), atol=1e-10) (auto-spectra imaginary part ~zero)

    TEST-09: `test_csd_sine_injection_roundtrip`
    - Use sine_epochs fixture (20 epochs, 2 channels, 10 Hz sine + noise)
    - Call epochs_to_csd(sine_epochs, fmin=1.0, fmax=50.0, n_freqs=50)
    - Find target bin: target_idx = torch.argmin(torch.abs(freqs - 10.0))
    - Find peak bin: peak_idx = torch.argmax(csd[:, 0, 0].real)
    - Assert abs(peak_idx - target_idx) <= 1 with descriptive error message showing actual vs expected frequencies

    TEST-10: `test_require_mne_import_error`
    - Use monkeypatch to temporarily make mne un-importable:
      ```python
      import builtins
      real_import = builtins.__import__
      def mock_import(name, *args, **kwargs):
          if name == "mne":
              raise ImportError("No module named 'mne'")
          return real_import(name, *args, **kwargs)
      monkeypatch.setattr(builtins, "__import__", mock_import)
      ```
    - Call _require_mne() inside pytest.raises(ImportError, match=r"pip install pyro-dcm\[mne\]")

    TEST-11: `test_epochs_to_csd_invalid_method`
