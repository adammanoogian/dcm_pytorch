    Create `tests/test_bids_loader.py` with the following structure and tests. The file must follow all project conventions: `from __future__ import annotations`, NumPy-style docstrings, type hints, 88-char line length, ruff-clean.

    **File header and imports:**
    ```python
    from __future__ import annotations

    import numpy as np
    import pytest

    mne = pytest.importorskip("mne")
    mne_bids = pytest.importorskip("mne_bids")

    from pyro_dcm.io.bids_loader import load_bids_epochs, load_bids_raw

    pytestmark = pytest.mark.mne
    ```

    Note: Both `mne` AND `mne_bids` must be importorskip'd since BIDS tests need both.

    **Helper function:**

    `_make_bids_dataset(tmp_path, ...)` — helper (not a fixture, to allow per-test customization) that:
    1. Creates mne.create_info with given ch_names, sfreq, ch_types="eeg"
    2. Sets info["line_freq"] = 50.0 (BIDS requirement — Pitfall 5)
    3. Creates RawArray from random data * 1e-6 (Volts — Pitfall 3)
    4. Optionally adds annotations (for events and BAD segments)
    5. Creates BIDSPath(subject="01", task="test", datatype="eeg", root=tmp_path)
    6. Calls write_raw_bids(raw, bids_path, overwrite=True, verbose=False)
    7. Returns bids_path

    **Tests:**

    BIDS-01: `test_load_bids_raw`
    - Create a synthetic BIDS dataset: 3 EEG channels ("EEG1", "EEG2", "EEG3"), 256 Hz, 10 seconds of random data.
    - Use _make_bids_dataset helper to write to tmp_path.
    - Call load_bids_raw(bids_path)
    - Assert isinstance(raw_loaded, mne.io.BaseRaw)
    - Assert the loaded raw has at least the 3 original EEG channels (write_raw_bids may add a STIM channel for events, so use `>=` or check channel names are a subset).
    - Assert raw_loaded.info["sfreq"] == 256.0
    - Assert raw_loaded.n_times > 0 (data was loaded)

    BIDS-02: `test_load_bids_epochs`
    - Create a synthetic BIDS dataset: 2 EEG channels, 256 Hz, 30 seconds.
    - Add event annotations: stimulus events at regular intervals (e.g., every 3 seconds from 1.0 to 25.0).
      ```python
      onsets = np.arange(1.0, 25.0, 3.0)
      annotations = mne.Annotations(
          onset=onsets,
          duration=np.zeros(len(onsets)),
          description=["stimulus"] * len(onsets),
      )
      raw.set_annotations(annotations)
      ```
    - Write to BIDS, then call load_bids_epochs(bids_path, event_id={"stimulus": 1}, tmin=-0.1, tmax=0.4)
    - Assert isinstance(epochs, mne.Epochs)
    - Assert len(epochs) > 0 (some epochs were created)
    - Assert epochs.info["sfreq"] == 256.0

    NOTE on BIDS-02 event_id: `write_raw_bids` converts annotations to events. When reading back, `mne.events_from_annotations(raw)` auto-assigns integer codes. The annotation description "stimulus" gets an auto-assigned code (usually 1, but may differ). The `load_bids_epochs` function uses `events_from_annotations` which returns an `auto_event_id` dict. When we pass `event_id={"stimulus": 1}`, it may not match the auto-assigned ID.

    SAFER approach: Call load_bids_epochs with event_id=None (uses auto-detected events). Then verify epochs were created. Alternatively, check what event_id the BIDS round-trip produces and match accordingly. The safest test is:
    ```python
    epochs = load_bids_epochs(bids_path, event_id=None, tmin=-0.1, tmax=0.4)
    ```

    BIDS-03: `test_bids_bad_acq_skip_annotation`
    - Create a synthetic BIDS dataset: 2 EEG channels, 256 Hz, 30 seconds.
    - Add annotations combining stimulus events AND a BAD_ACQ_SKIP segment:
      ```python
      event_onsets = np.arange(1.0, 25.0, 3.0)  # ~8 events
      annotations = mne.Annotations(
          onset=list(event_onsets) + [10.0],
          duration=[0.0] * len(event_onsets) + [2.0],
          description=["stimulus"] * len(event_onsets) + ["BAD_ACQ_SKIP"],
      )
      raw.set_annotations(annotations)
      ```
    - Write to BIDS, then load epochs with event_id=None, tmin=-0.1, tmax=0.4.
    - Assert isinstance(epochs, mne.Epochs)
    - The BAD_ACQ_SKIP annotation creates a 2-second gap at t=10s. Epochs whose data window overlaps this gap should be automatically rejected by MNE.
    - Assert len(epochs) < len(event_onsets) — some epochs were dropped due to BAD_ACQ_SKIP overlap.
    - If MNE does NOT auto-reject epochs overlapping BAD_ACQ_SKIP, the test should still pass as long as no error is raised (the primary goal is "handled without error"). Adjust assertion accordingly: at minimum assert len(epochs) >= 1.

    **Edge case awareness for BIDS tests:**
    - info["line_freq"] MUST be set (Pitfall 5 from research)
    - Data must be in Volts (multiply by 1e-6, Pitfall 3)
    - write_raw_bids may add channels; don't assert exact channel count equality
    - Event annotation round-trip may change event codes; use event_id=None for safety
    - BIDS-03 is primarily a "does not crash" test; the exact epoch rejection count depends on MNE version behavior with BAD_ACQ_SKIP
    - Use rng = np.random.default_rng(42) for all random data

    - No external data downloads
    - Each test function under 50 lines
    - Descriptive assertion messages with expected vs actual values
