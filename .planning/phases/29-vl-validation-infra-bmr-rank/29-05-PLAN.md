Content:
- The determinism contract: fixed seed + identical inputs + identical max_iter ->
  reproducible posterior means within atol 1e-8 across all three forward models
  (spectral, task, latent-circuit), verified by `tests/test_vl_determinism.py`.
- Known non-determinism sources that can introduce sub-1e-8 jitter:
  * BLAS / threadpool reduction order (set `OMP_NUM_THREADS` / `MKL_NUM_THREADS` for
    bitwise reproducibility on a single machine; cross-machine bitwise equality is NOT
    guaranteed).
  * float64 accumulation order in `torch.linalg.solve` / `slogdet` / `cholesky`.
  * ODE solver (rk4) step accumulation for task / latent-circuit forward models.
  * Finite-difference Jacobian step (`exp(-8)`) is deterministic but scale-sensitive
    (pitfall N5) — note it is fixed, not random.
- Multi-restart note (pitfall N4): the restart PATH is deterministic given a fixed
  restart-seed schedule; the SELECTED mode depends on which basin each restart lands in,
  which is reproducible but NOT guaranteed to be the global optimum.
- Cross-machine caveat: M3 cluster vs laptop may differ below atol 1e-6 due to
  different BLAS builds; Phase 30 must compare within-machine, not bitwise across
  machines.

NumPy/markdown prose; cite pitfalls N4, N5 and VLROBUST-01.
  </action>
