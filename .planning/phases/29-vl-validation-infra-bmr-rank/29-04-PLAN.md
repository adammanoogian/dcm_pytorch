  <name>Task 1: Implement run_spectral_vl and run_task_vl runners</name>
  <files>benchmarks/runners/spectral_vl.py, benchmarks/runners/task_vl.py</files>
  <action>
Create two runners following the EXACT `(config: BenchmarkConfig) -> dict[str, Any]`
signature of `run_spectral_svi`, but fitting via Variational Laplace instead of SVI.

`benchmarks/runners/spectral_vl.py` — `run_spectral_vl(config)`:
- Loop `for i in range(config.n_datasets):` with `seed_i = config.seed + i`.
- Generate ground truth inline (mirror spectral_svi's `fixtures_dir is None` branch):
  `A_true = make_stable_A_spectral(N, seed=seed_i)`;
  `sim = simulate_spectral_dcm(A_true, TR=2.0, n_freqs=32, seed=seed_i)`; extract the
  observed CSD tensor (shape (F, N, N) complex) and `a_mask = torch.ones(N, N)` exactly
  as spectral_svi does. N = `config.n_regions`.
- Fit: build `forward = SpectralDCMForward()`; call
  `result = run_variational_laplace_generic(forward, observed=csd_obs, a_mask=a_mask,
  n_regions=N, max_iter=(config.max_iter or 128), context={})`.
  (Pass `prior_variance=1.0/64.0` default; if `config.hyperprior_mean` etc. are set,
  thread them through ONLY if the engine signature accepts them — it does not in
  `run_variational_laplace_generic`, so for this phase leave SPM-matched params for
  Phase 32; do NOT invent kwargs the engine lacks.)
- Extract: `posterior = extract_vl_posterior_generic(result, forward, N)`;
  `A_free_mean = posterior["A_free"]["mean"]`; `A_inferred = parameterize_A(A_free_mean
  * a_mask)`.
- Metrics per dataset: `rmse = compute_rmse(A_true, A_inferred)`; coverage via
  `compute_coverage_from_samples` using `posterior["A_free"]["samples"]` mapped through
  `parameterize_A` (reuse the exact coverage helper signature in metrics.py — read it
  first). Record `converged = bool(result.converged)` and `result.n_iterations` if
  available on the result.
- Wrap each dataset in try/except; on failure append a record with `"error"` and
  continue (mirror spectral_svi's robustness; print a one-line message).
- Return a dict with: `variant="spectral"`, `method="vl"`, `n_regions=N`,
  per-dataset lists (`rmse_list`, `coverage_list`, `converged_list`,
  `a_true_list`, `a_inferred_list`), and `compute_summary_stats(rmse_list)` aggregated
  under a `"summary"` key. Keep the return-dict shape parallel to `run_spectral_svi`
  so the figure pipeline can consume it.

`benchmarks/runners/task_vl.py` — `run_task_vl(config)`:
- Mirror `run_task_svi`'s inline-generation branch for ground truth: build a block
  stimulus via `make_block_stimulus`, simulate via `simulate_task_dcm`, build `c_mask`.
- CRITICAL: use a coarse model dt for the VL forward (dt = 0.1, NOT 0.01) so the
  `(T*N, T*N)` precision matrix stays within the guard added in Plan 29-03. Build
  `t_eval = torch.arange(0, duration, 0.5)` at TR resolution for the observed BOLD and
  pass `dt=0.1` (or coarser) to `TaskDCMForward(stimulus_fn=..., c_mask=..., t_eval=...,
  dt=0.1)`. Keep observed BOLD length small (e.g. duration ~ 120s at TR=2 -> 60 points)
  so T*N stays well under the 5000 cap.
- Fit with `run_variational_laplace_generic(forward, observed=bold, a_mask=a_mask,
  n_regions=N, max_iter=(config.max_iter or 128), context={"a_mask": a_mask})`.
  (Note: TaskDCMForward.predict reads `context["a_mask"]` — pass it.)
- Extract posterior, compute A-RMSE + convergence as in the spectral runner. Return the
  same dict shape with `variant="task"`, `method="vl"`.

Both files: `from __future__ import annotations`; NumPy docstrings citing this plan;
absolute imports only; ruff + mypy clean. Import forward models / VL engine from
`pyro_dcm.inference`. Import metrics from `benchmarks.metrics`.
  </action>
  <verify>
`python -c "from benchmarks.config import BenchmarkConfig; from benchmarks.runners.spectral_vl import run_spectral_vl; c=BenchmarkConfig(variant='spectral', method='vl', n_datasets=1, n_regions=2, max_iter=16, seed=0); r=run_spectral_vl(c); print(r['method'], len(r['rmse_list']))"`
prints `vl 1`. Same for task_vl with `n_regions=2, max_iter=16`, completing in well
under 60s. `ruff check benchmarks/runners/spectral_vl.py benchmarks/runners/task_vl.py`
and `mypy` clean.
  </verify>
  <done>
run_spectral_vl and run_task_vl each accept a BenchmarkConfig, fit via VL, and return
a results dict with per-dataset A-RMSE + convergence; task_vl runs at dt>=0.1 so the
precision guard never trips.
  </done>
