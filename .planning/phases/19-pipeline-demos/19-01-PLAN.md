1. **Module docstring** stating purpose, expected runtime (~1-2 min on CPU), and
   what it produces (posterior A matrix with recovery metrics).

2. **MNE import guard** at top of file:
   ```python
   try:
       import mne
   except ImportError:
       print("MNE-Python required. Install with: pip install pyro-dcm[mne]")
       sys.exit(1)
   ```
   Import `sys` in the stdlib block for this.

3. **Imports** from pyro_dcm:
   - `simulate_spectral_dcm`, `make_stable_A_spectral`, `parameterize_A` (ground truth)
   - `spectral_dcm_model`, `create_guide`, `run_svi`, `extract_posterior_params` (fitting)
   - `epochs_to_csd` from `pyro_dcm.io` (MNE IO bridge)

4. **main() function** with numbered sections (`# --- N. Section name ---`):

   **Section 1: Ground-truth A matrix.**
   Use `make_stable_A_spectral(n_regions=3, connection_strength=0.1, seed=42)` to
   get a stable A_true. Print A_true for reference.

   **Section 2: Simulate CSD from ground truth.**
   Call `simulate_spectral_dcm(A_true, n_freqs=32, seed=42)` to get a dict with
   `'csd'` (F, N, N) complex and `'freqs'` (F,) float. This is the "known truth"
   CSD we will try to recover from.

   **Section 3: Create synthetic MNE Epochs.**
   This section demonstrates wrapping data in MNE format. Since we already have
   the CSD from simulation, we need MNE Epochs to pass through `epochs_to_csd`.
   Create a synthetic EpochsArray with noise data:
   ```python
   rng = np.random.default_rng(42)
   N = 3
   sfreq = 256.0
   n_epochs_mne = 20
   n_times = int(sfreq * 2.0)  # 2s epochs
   info = mne.create_info(
       ch_names=[f"ROI{i}" for i in range(N)],
       sfreq=sfreq,
       ch_types="eeg",
   )
   data = rng.standard_normal((n_epochs_mne, N, n_times)) * 1e-6
   epochs = mne.EpochsArray(data, info)
   ```

   **Section 4: MNE Epochs -> CSD tensor (the IO bridge).**
   Call `epochs_to_csd(epochs, fmin=1.0, fmax=50.0, n_freqs=32)`.
   Get `observed_csd` and `freqs` from the result dict.
   Print shapes for user visibility.

   IMPORTANT DESIGN NOTE: For a meaningful recovery demo, we use the CSD from
   `simulate_spectral_dcm` (Section 2) as `observed_csd` for fitting, NOT the
   MNE-derived CSD from Section 4. Section 3-4 exist to demonstrate the
   `epochs_to_csd` IO bridge end-to-end. Add a clear comment:
   ```python
   # For this demo, we use the simulated CSD (with known ground truth) for
   # fitting so we can measure recovery quality. In a real workflow, you would
   # use mne_csd from epochs_to_csd as your observed data.
   observed_csd = sim_result["csd"]
   freqs = sim_result["freqs"]
   ```

   **Section 5: Set up model and fit via SVI.**
   ```python
   a_mask = torch.ones(N, N, dtype=torch.float64)
   model_args = (observed_csd, freqs, a_mask)
   guide = create_guide(spectral_dcm_model, init_scale=0.01)
   svi_result = run_svi(
       spectral_dcm_model, guide, model_args,
       num_steps=300, lr=0.01,
   )
   ```

   **Section 6: Extract posterior and compute recovery metrics.**
   ```python
   posterior = extract_posterior_params(guide, model_args)
   A_est = parameterize_A(posterior["A_free"]["mean"])
   a_rmse = torch.sqrt(((A_est - A_true) ** 2).mean()).item()
   ```
   Print: final ELBO loss (mean of last 10), A_true, A_est, A-RMSE.

5. **`if __name__ == "__main__": main()` guard.**

6. **Coding standards:** `from __future__ import annotations`, NumPy-style docstring
   for main(), line length 88, ruff-clean. No wildcard imports. Use torch.float64
   (double precision) throughout.
