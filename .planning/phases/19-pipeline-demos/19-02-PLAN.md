  <name>Task 1: Create task DCM pipeline demo script</name>

  <action>
Create `scripts/demo_task_dcm.py` following the exact structure of
`scripts/demo_bilinear_consumer.py`. The script must:

1. **Module docstring** stating purpose, expected runtime (~2-5 min on CPU), and
   what it produces (posterior A + B matrices with recovery metrics).

2. **MNE import guard** at top of file:
   ```python
   try:
       import mne
   except ImportError:
       print("MNE-Python required. Install with: pip install pyro-dcm[mne]")
       sys.exit(1)
   ```
   Import `sys` in the stdlib block for this.

3. **Imports** from pyro_dcm:
   - `parameterize_A`, `parameterize_B` (transforms)
   - `simulate_task_dcm`, `make_block_stimulus`, `make_event_stimulus` (simulation)
   - `PiecewiseConstantInput` (stimulus wrapper)
   - `task_dcm_model`, `create_guide`, `run_svi`, `extract_posterior_params` (fitting)
   - `epochs_to_timeseries` from `pyro_dcm.io` (MNE IO bridge)

4. **main() function** with numbered sections (`# --- N. Section name ---`):

   **Section 1: Simulation config.**
   Keep deliberately small for local-friendly demo:
   ```python
   N_REGIONS = 3
   DURATION = 100.0  # seconds
   DT_SIM = 0.01     # simulation ODE step
   DT_MODEL = 0.5    # model ODE step (coarser for SVI speed)
   TR = 2.0           # repetition time
   SNR = 3.0
   NUM_SVI_STEPS = 100
   ```

   **Section 2: Ground-truth DCM circuit.**
   Set up A_true via `parameterize_A`:
   ```python
   A_free_true = torch.zeros(N_REGIONS, N_REGIONS, dtype=torch.float64)
   A_free_true[1, 0] = 0.3   # region 0 -> 1
   A_free_true[2, 1] = 0.3   # region 1 -> 2
   A_true = parameterize_A(A_free_true)
   ```

   Set up C_true (driving input into region 0):
   ```python
   C_true = torch.zeros(N_REGIONS, 1, dtype=torch.float64)
   C_true[0, 0] = 0.5
   ```

   Set up bilinear B (modulator gates 0->1 edge):
   ```python
   b_mask = torch.zeros(1, N_REGIONS, N_REGIONS, dtype=torch.float64)
   b_mask[0, 1, 0] = 1.0
   B_free_true = torch.zeros(1, N_REGIONS, N_REGIONS, dtype=torch.float64)
   B_free_true[0, 1, 0] = 0.4
   B_true = parameterize_B(B_free_true, b_mask)
   ```

   **Section 3: Stimulus construction.**
   Driving input: block design.
   ```python
   stimulus = make_block_stimulus(
       n_blocks=3, block_duration=15.0, rest_duration=15.0, n_inputs=1,
   )
   ```
   Modulator: epoch stimulus aligned with blocks (simple boxcar modulator).
   Use `make_event_stimulus` with 3 event times at block onsets, amplitude=1.0:
   ```python
   stim_mod_dict = make_event_stimulus(
       event_times=[10.0, 40.0, 70.0],
       event_amplitudes=[1.0, 1.0, 1.0],
       duration=DURATION, dt=DT_SIM, n_inputs=1,
   )
   stim_mod = PiecewiseConstantInput(
       stim_mod_dict["times"], stim_mod_dict["values"],
   )
   ```

   **Section 4: Forward simulation.**
   ```python
   B_list = [B_true[j] for j in range(B_true.shape[0])]
   sim = simulate_task_dcm(
       A=A_true, C=C_true, stimulus=stimulus,
       duration=DURATION, dt=DT_SIM, TR=TR, SNR=SNR, seed=42,
       B_list=B_list, stimulus_mod=stim_mod,
   )
   observed_bold_sim = sim["bold"]      # (T_obs, N) at TR resolution
   ```

   **Section 5: Wrap simulated BOLD in MNE Epochs (the IO bridge).**
   Create an EpochsArray at `sfreq=1/TR` from the simulated BOLD:
   ```python
   sfreq = 1.0 / TR  # 0.5 Hz for TR=2.0
   n_timepoints = observed_bold_sim.shape[0]
   # MNE expects (n_epochs, n_channels, n_times) -- use 1 epoch for averaged data
   mne_data = observed_bold_sim.numpy().T[np.newaxis, :, :]  # (1, N, T)
   info = mne.create_info(
       ch_names=[f"ROI{i}" for i in range(N_REGIONS)],
       sfreq=sfreq,
       ch_types="misc",
   )
   epochs = mne.EpochsArray(mne_data, info)
   ```

   **Section 6: MNE Epochs -> timeseries tensor.**
   ```python
   ts_result = epochs_to_timeseries(epochs, average=True)
   observed_bold = ts_result["timeseries"]   # (T, N)
   ```
   Print shapes for user visibility. Add comment noting that in a real workflow,
   the Epochs would come from loaded fMRI data, not simulation.

   **Section 7: Set up model args and fit via SVI.**
   ```python
   T_total = DURATION
   t_eval = torch.arange(0, T_total, DT_MODEL, dtype=torch.float64)

   a_mask = torch.ones(N_REGIONS, N_REGIONS, dtype=torch.float64)
   c_mask = torch.zeros(N_REGIONS, 1, dtype=torch.float64)
   c_mask[0, 0] = 1.0
   b_masks_list = [b_mask[j] for j in range(b_mask.shape[0])]

   model_args = (observed_bold, stimulus, a_mask, c_mask, t_eval, TR, DT_MODEL)
   model_kwargs = {"b_masks": b_masks_list, "stim_mod": stim_mod}

   guide = create_guide(task_dcm_model, init_scale=0.01, n_regions=N_REGIONS)
   svi_result = run_svi(
       task_dcm_model, guide, model_args,
       num_steps=NUM_SVI_STEPS, lr=0.01,
       model_kwargs=model_kwargs,
   )
   ```

   CRITICAL: `t_eval` must be constructed from DURATION and DT_MODEL, NOT from
   `ts_result["times"]`. The `times` from epochs_to_timeseries is at TR resolution;
   `t_eval` must be at DT_MODEL resolution. This is Pitfall 1 from the research.

   **Section 8: Extract posterior and compute recovery metrics.**
   ```python
   from functools import partial
   model_for_pred = partial(task_dcm_model, **model_kwargs)
   posterior = extract_posterior_params(
       guide=guide, model_args=model_args,
       model=model_for_pred, num_samples=200,
   )
   A_est = posterior["median"]["A"]
   B_est = posterior["median"]["B"]
   ```
   Compute and print: final ELBO (mean of last 10), A-RMSE, B-RMSE on masked
   non-zero elements, B sign recovery, A_true vs A_est, B_true vs B_est.
   Follow exactly the recovery reporting pattern from `demo_bilinear_consumer.py`.

5. **`if __name__ == "__main__": main()` guard.**

6. **Coding standards:** `from __future__ import annotations`, NumPy-style docstring
   for main(), line length 88, ruff-clean. No wildcard imports. torch.float64
   throughout.

ANTI-PATTERNS to avoid (from 19-RESEARCH.md):
- Do NOT use `dt=0.01` for the model/SVI -- use `DT_MODEL=0.5` (Pitfall from research)
- Do NOT use `average=False` -- observed_bold must be (T, N) not (n_epochs, T, N)
- Do NOT construct t_eval from ts_result["times"] -- build from DURATION and DT_MODEL
- Do NOT call `pyro.clear_param_store()` -- run_svi does it
- Do NOT import mne at top level unconditionally -- use try/except guard
- Do NOT pass model_kwargs as positional arg to run_svi -- it's keyword-only
