  <action>
    **1. Create `scripts/train_rnn_seed.py`:**
    - `from __future__ import annotations`
    - Argparse CLI with arguments:
      - `--seed` (int, required): random seed
      - `--hidden` (int, default=256): hidden units H
      - `--n-steps` (int, default=3000): training steps
      - `--lr` (float, default=1e-3): learning rate
      - `--batch-size` (int, default=32): training batch size
      - `--seq-len` (int, default=100): sequence length
      - `--grad-clip` (float, default=1.0): gradient clip norm
      - `--noise-std` (float, default=0.05): hidden state noise during training
      - `--tau` (float, default=1.0): time constant
      - `--dt` (float, default=0.1): integration step (alpha = dt/tau)
      - `--criterion-acc` (float, default=0.85): early stopping accuracy
      - `--n-eval-trials` (int, default=100): evaluation trials
      - `--output-dir` (str, default="."): base output directory
      - `--skip-trajectories` (flag): skip trajectory extraction
      - `--n-pca-components` (int, default=None): if set, run PCA after extraction
    - Workflow:
      1. Set `torch.manual_seed(seed)` and `np.random.seed(seed)`
      2. Create neurogym CDDM env to get `ob_size` and `act_size`
      3. Create `ContinuousTimeRNN(n_input=ob_size, n_hidden=hidden, n_output=act_size,
         tau=tau, dt=dt, noise_std=noise_std)`
      4. Call `train_rnn(rnn, n_steps=n_steps, lr=lr, ...)`
      5. Call `eval_rnn_performance(rnn, ...)` and check accuracy >= criterion_acc
      6. Save weights: `torch.save(rnn.state_dict(), checkpoints_dir / f"seed_{seed:04d}_H{hidden:03d}.pt")`
      7. Save metadata JSON: `{"seed": seed, "H": hidden, "accuracy": ..., "n_steps": ...,
         "tau": tau, "dt": dt, "alpha": dt/tau, "dt_seconds": env.dt/1000, ...}`
      8. If not `--skip-trajectories`: extract trajectories, save as `.npz` files
         Include metadata in npz: `dt_seconds`, `tau`, `alpha`, `n_steps_per_trial`
      9. If `--n-pca-components` set: run PCA, report variance explained, run output-R2 gate
      10. Print summary: seed, accuracy, n_steps, trajectory shapes, PCA results if applicable
    - Create output directories if they don't exist:
      `{output_dir}/checkpoints/rnn/`, `{output_dir}/data/rnn_trajectories/`

    **2. Create `cluster/scripts/train_rnn_ensemble.py`:**
    - Wrapper that reads `SLURM_ARRAY_TASK_ID` env var for seed
    - Sets up paths relative to project root (assumes Mutagen sync)
    - Calls the same training logic as `train_rnn_seed.py`
    - Logs to stdout for SLURM capture
    - Handles H values: default H=256, but configurable via env var `RNN_HIDDEN`
    - At end of training, runs trajectory extraction (same seed)
    - Reports timing and memory usage

    **3. Create `cluster/sbatch/rnn_train_array.sbatch`:**
    - Follow existing pattern from `cluster/sbatch/lc_calibration.sbatch`
    - SLURM directives:
      ```
      #SBATCH --job-name=rnn_train_phase21
      #SBATCH --array=0-19
      #SBATCH --ntasks=1
      #SBATCH --cpus-per-task=4
      #SBATCH --mem=8G
      #SBATCH --time=01:30:00
      #SBATCH --output=cluster/logs/rnn_train_%A_%a.out
      #SBATCH --error=cluster/logs/rnn_train_%A_%a.err
      ```
    - Load conda/module environment (follow pattern from existing sbatch scripts)
    - Run: `python cluster/scripts/train_rnn_ensemble.py`
    - Comment: estimated runtime 30-60 min per seed, 20 seeds parallel = ~60 min wall
    - Comment: trajectory storage estimate ~100MB per seed x 20 = ~2GB total

    **Anti-patterns to avoid:**
    - Do NOT run all 20 seeds sequentially in one job (use --array for parallelism)
    - Do NOT save trajectories as .pt tensors (use .npz for consistency with fixture pattern)
    - Do NOT hardcode paths -- use argparse or env vars
    - Do NOT forget dt_seconds metadata in saved trajectories (pitfall LC10)
