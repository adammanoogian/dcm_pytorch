    **1. Create `src/pyro_dcm/rnn/fixed_point_analysis.py`:**
    - `from __future__ import annotations`

    **`find_fixed_points()`:**
    ```
    def find_fixed_points(
        rnn: ContinuousTimeRNN,
        u_context: torch.Tensor,    # (M_in,) fixed input context
        n_inits: int = 100,
        n_steps: int = 5000,
        lr: float = 1e-3,
        tol: float = 1e-12,
        convergence_threshold: float = 1e-6,
    ) -> list[torch.Tensor]:
    ```
    - For each init: create `h = nn.Parameter(torch.randn(rnn.n_hidden) * 0.1)`
    - Optimize `||dh/dt||^2 = ||-h + f(W_rec @ h + W_in @ u + b)||^2` via Adam
    - Converged if `loss < tol`, keep if `loss < convergence_threshold`
    - After all inits, deduplicate fixed points within L2 distance threshold (e.g., 1e-3)
    - Return list of `(H,)` tensors (detached)
    - Use `torch.no_grad()` context for deduplication but NOT for optimization (need grads)
    - Access RNN internals via `rnn.W_rec`, `rnn.W_in`, `rnn.b`, `rnn.f`

    **`_deduplicate_fixed_points()`:**
    - Private helper: given list of tensors, merge points within L2 distance < threshold
    - Return deduplicated list

    **`compute_jacobian_at_fp()`:**
    ```
    def compute_jacobian_at_fp(
        rnn: ContinuousTimeRNN,
        h_star: torch.Tensor,    # (H,) fixed point
        u: torch.Tensor,         # (M_in,) input at fixed point
    ) -> torch.Tensor:
    ```
    - Define `dynamics(h) = -h + rnn.f(rnn.W_rec @ h + rnn.W_in @ u + rnn.b)`
    - Use `torch.autograd.functional.jacobian(dynamics, h_star)` -> `(H, H)` tensor
    - Return the Jacobian

    **`classify_stability()`:**
    ```
    def classify_stability(jacobian: torch.Tensor) -> dict:
    ```
    - Compute eigenvalues via `torch.linalg.eig(jacobian).eigenvalues`
    - Return dict with keys: `eigenvalues` (complex tensor), `stable` (bool: all real parts < 0),
      `n_unstable` (int: count of eigenvalues with real part >= 0),
      `max_real_part` (float: maximum real part)

    - Save dt_seconds = env.dt / 1000 in returned dict metadata

    **`pca_reduce()`:**

    ```
        h_all: np.ndarray,     # (n_samples, H) all trajectories stacked

    ```
    - Fit sklearn PCA, return (fitted PCA, projected data of shape (n_samples, n_components))

    **`variance_explained_diagnostic()`:**
    ```
    def variance_explained_diagnostic(pca: PCA) -> dict:
    ```
    - Compute cumulative = `np.cumsum(pca.explained_variance_ratio_)`
    - Compute marginal = individual explained_variance_ratio_ values
    - Compute recommended_n: first N where the NEXT component's marginal gain < 5%
      (i.e., `pca.explained_variance_ratio_[n] < 0.05` for first such n, recommended = n)
      If no component drops below 5%, recommended_n = number of components fitted
    - Return dict: `{"cumulative": np.ndarray, "marginal": np.ndarray, "recommended_n": int}`

    **`output_r_squared_gate()`:**
    ```
    def output_r_squared_gate(
        h_projected: np.ndarray,    # (n_samples, N) PCA-projected
        z_true: np.ndarray,         # (n_samples, act_size) true behavioral readout
        w_out: np.ndarray,          # (act_size, H) RNN output weights
        pca: PCA,                   # fitted PCA
        threshold: float = 0.90,
    ) -> dict:
    ```
    - Compute W_out in PCA space: `w_out_pca = w_out @ pca.components_.T` -> (act_size, N)
    - Reconstruct: `z_pred = h_projected @ w_out_pca.T` -> (n_samples, act_size)
    - R-squared: `1 - sum((z_true - z_pred)^2) / sum((z_true - z_true.mean(0))^2)`
    - Return dict: `{"r_squared": float, "passed": bool, "threshold": float}`
    - Guard against zero variance: `max(ss_tot, 1e-12)` in denominator

    **`zscore_trajectories()`:**
    ```
    def zscore_trajectories(
        h_projected: np.ndarray,    # (n_samples, N)
    ) -> tuple[np.ndarray, np.ndarray, np.ndarray]:
    ```
    - Z-score each PC to zero mean, unit variance (pitfall LC4)
    - Return `(z_scored, means, stds)` for inverse normalization later
    - Handle near-zero std: clip std to min 1e-8
