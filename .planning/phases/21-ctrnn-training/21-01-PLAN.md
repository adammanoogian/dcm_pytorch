    **1. Create `src/pyro_dcm/rnn/__init__.py`:**

    - Add `__all__` list with `ContinuousTimeRNN` (will be extended by later plans)

    **2. Create `src/pyro_dcm/rnn/continuous_time_rnn.py`:**
    - `from __future__ import annotations`
    - Implement `ContinuousTimeRNN(nn.Module)` with the following:
      - Constructor args: `n_input: int`, `n_hidden: int`, `n_output: int`,
        `tau: float = 1.0`, `dt: float = 0.1`, `activation: str = "relu"`,
        `noise_std: float = 0.0`
      - Compute `alpha = dt / tau` in `__init__`, store as non-learnable buffer or attribute
      - Weight matrices as `nn.Parameter`:
        - `W_rec`: shape `(n_hidden, n_hidden)`, init `Normal(0, 1/sqrt(n_hidden))`
        - `W_in`: shape `(n_hidden, n_input)`, init `Normal(0, 1/sqrt(n_input))`
        - `W_out`: shape `(n_output, n_hidden)`, init `Normal(0, 1/sqrt(n_hidden))`
        - `b`: shape `(n_hidden,)`, init zeros
      - Activation: `torch.relu` if `activation == "relu"`, `torch.tanh` if `activation == "tanh"`;
        raise `ValueError` for unknown activation. Store as `self.f` (callable).
      - `forward(self, u: torch.Tensor, h0: torch.Tensor | None = None) -> tuple[torch.Tensor, torch.Tensor]`:
        - Input `u` shape: `(T, B, M_in)` where T=timesteps, B=batch, M_in=input_dim.
          Also accept `(T, M_in)` and unsqueeze to `(T, 1, M_in)`.
        - If `h0 is None`, init to `torch.zeros(B, n_hidden)`
        - Euler loop: `h = (1 - alpha) * h + alpha * f(h @ W_rec.T + u[t] @ W_in.T + b)`
        - If `self.training and self.noise_std > 0`: add `noise_std * torch.randn_like(h)`
        - Collect `h_traj`: stack along dim 0 -> `(T, B, H)`
        - Readout: `z = h_traj @ W_out.T` -> `(T, B, M_out)`
        - Return `(z, h_traj)`
    - NumPy-style docstring citing Langdon & Engel (2025) for the CT-RNN equation:
      `tau * dh/dt = -h + f(W_rec @ h + W_in @ u + b)`, Euler: `h[t+1] = (1-alpha)*h[t] + alpha*f(...)`.
      Note: formal reference ID will be assigned in Phase 25 (PUB-03).
    - Document shape conventions in docstring Parameters/Returns sections

    **3. Update `pyproject.toml`:**
    - Add `latent` optional dependency group:

    - Do NOT use `torchdiffeq.odeint` for the RNN forward pass (Euler is correct per research)

    - Do NOT make alpha a learnable parameter (fixed for v0.6.0)
    - Do NOT use `torch.inverse` anywhere (use `torch.linalg.solve` if needed)

  <action>
    Create `tests/test_ctrnn.py` with the following tests:

    1. **test_forward_shape_batched**: Create CT-RNN (n_input=6, n_hidden=64, n_output=3),
       pass `u = torch.randn(100, 16, 6)`, assert `z.shape == (100, 16, 3)` and
       `h.shape == (100, 16, 64)`.

    2. **test_forward_shape_unbatched**: Pass `u = torch.randn(100, 6)` (no batch dim),
       assert outputs have batch dim 1 inserted.

    3. **test_alpha_computation**: Create CT-RNN with `tau=2.0, dt=0.1`, assert
       `rnn.alpha == 0.05`.

    4. **test_relu_activation**: Create CT-RNN with `activation="relu"`, run forward,
       check that hidden states are non-negative where they should be (ReLU property:
       the post-activation part is non-negative).

    5. **test_tanh_activation**: Create CT-RNN with `activation="tanh"`, run forward,
       assert hidden states are in [-1, 1] range (bounded by tanh).

    6. **test_invalid_activation**: Assert `ValueError` raised for `activation="sigmoid"`.

    7. **test_gradient_flow**: Create CT-RNN, run forward on random input, compute
       `loss = z.sum()`, call `loss.backward()`. Assert all parameters have non-None
       `.grad` with at least some non-zero values (BPTT works).

    8. **test_h0_custom**: Pass a custom `h0 = torch.ones(16, 64)`, verify first hidden
       state differs from the zero-init case.

    9. **test_noise_injection_training**: Create CT-RNN with `noise_std=0.1`. Run forward
       twice in training mode with same input but different random states. Hidden
       trajectories should differ (noise injected). In eval mode, trajectories should
       be identical (no noise).

    10. **test_weight_shapes**: Assert W_rec is (H, H), W_in is (H, M_in), W_out is
        (M_out, H), b is (H,).

    All tests should use `from __future__ import annotations`, use small dimensions
    (H=16 or 32) for speed, and NOT require neurogym (pure PyTorch tests, no markers).
