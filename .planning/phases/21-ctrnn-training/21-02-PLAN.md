    - `from __future__ import annotations`

    **`train_rnn()` function:**
    ```
    def train_rnn(
        rnn: ContinuousTimeRNN,
        task: str = "ContextDecisionMaking-v0",
        env_kwargs: dict | None = None,
        n_steps: int = 3000,
        batch_size: int = 32,
        seq_len: int = 100,
        lr: float = 1e-3,
        grad_clip: float = 1.0,
        criterion_acc: float = 0.85,
        log_every: int = 100,
        device: torch.device | None = None,
    ) -> dict:
    ```
    - Default `env_kwargs = {"dt": 100}` if None
    - Create `ngym.Dataset(task, env_kwargs=env_kwargs, batch_size=batch_size, seq_len=seq_len)`
    - Query `ob_size = dataset.env.observation_space.shape[0]` and
      `act_size = dataset.env.action_space.n` from the dataset's env
    - Validate: assert `rnn.n_input == ob_size` and `rnn.n_output == act_size` with
      informative error messages including expected vs actual values
    - Optimizer: `torch.optim.Adam(rnn.parameters(), lr=lr)`
    - Loss: `nn.CrossEntropyLoss()`
    - Training loop for `n_steps`:
      - `inputs, labels = dataset()`
      - Convert to tensors: `inputs = torch.tensor(inputs, dtype=torch.float32).to(device)`,
        `labels = torch.tensor(labels, dtype=torch.long).to(device)`
      - `z, h = rnn(inputs, h0=None)` -- z is (T, B, act_size)
      - `loss = criterion(z.reshape(-1, act_size), labels)`
      - Standard backward: `optimizer.zero_grad()`, `loss.backward()`,
        `nn.utils.clip_grad_norm_(rnn.parameters(), grad_clip)`, `optimizer.step()`
      - Compute accuracy: `(z.reshape(-1, act_size).argmax(dim=1) == labels).float().mean()`
      - Log every `log_every` steps: print step, loss, accuracy
      - Early stopping: if accuracy >= `criterion_acc` for 3 consecutive checks, break
    - Return dict: `{"final_loss": float, "final_accuracy": float, "n_steps_completed": int,
      "loss_history": list[float], "accuracy_history": list[float]}`

    **`eval_rnn_performance()` function:**
    ```
    def eval_rnn_performance(
        rnn: ContinuousTimeRNN,
        task: str = "ContextDecisionMaking-v0",
        env_kwargs: dict | None = None,
        n_eval_steps: int = 100,
        batch_size: int = 32,
        seq_len: int = 100,
        device: torch.device | None = None,
    ) -> dict:
    ```
    - Create fresh dataset, run RNN in eval mode (no noise), compute mean accuracy
      across `n_eval_steps` batches
    - Return: `{"accuracy": float, "n_trials": int}`

    **Anti-patterns to avoid:**
    - Do NOT hardcode `ob_size` or `act_size` -- always query from env
    - Do NOT use truncated BPTT -- trial length (~100-300 steps) is manageable for full BPTT
    - Do NOT import neurogym at module level -- import inside functions for optional dep pattern
      (users without neurogym installed should still be able to import other rnn functions)
