<objective>
Build the SAME-CSD bridge: extend the validation exporter so a Python-computed analytic
`(F, N, N)` complex CSD (the exact array the VL engine fits) is injected into the SPM12 `DCM.Y`
struct, and add a MATLAB batch script that makes `spm_nlsi_GN` fit THAT identical CSD rather than
recomputing CSD from BOLD via its internal MAR model.

Purpose: This is the crux that makes the strict 5%-matched-free-energy gate (user decision)
achievable. Python (analytic/Welch) and SPM (MAR) compute different CSDs from the same BOLD, so a
5% absolute-nat F agreement is only meaningful if BOTH engines evaluate free energy on the IDENTICAL
data. Pitfall S4 (column-major vs row-major) is the dominant hazard here: the CSD matrix must
round-trip Python -> .mat -> MATLAB with element `[w, i, j]` preserved and no silent transpose.

Output: `export_spectral_dcm_csd_for_spm()` in `validation/export_to_mat.py`, a new MATLAB script
`run_spm_spectral_dcm_csd_injected.m`, and a Python-side round-trip regression test.
</objective>
