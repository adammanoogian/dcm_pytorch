## Deviations from Plan

### Rule 4 - Architectural/scientific blocker (STOPPED, orchestrator decided Option A)

**1. [Rule 4 - Science does not hold forward-only] Frontal-dominance + global-negative-sign criteria amended**
- **Found during:** Task 2 (acceptance assertions)
- **Issue:** The plan's literal ERPDCM-04 criteria required machine-asserting (a) a global-negative-going rIFG difference wave at baseline and (b) frontal-dominance `max|diff[:,rIFG]| > max|diff[:,A1]|`. Both FAIL at the SPM-validated reference point and cannot be recovered forward-only:
  - **Frontal-dominance:** measured across **189 forward-only tunings** (a1_b_gain in [-2,1], rifg_b_gain in [0,8], flag in {both,forward,backward}); best `rIFG/A1` ratio = **0.062** (A1 dominates by >=16x, ~2000x at baseline). Root cause: `mmn_cmc_params` uses the LFP **identity** lead field (one channel per source, raw sp-voltage), so the input node A1 (direct evoked drive) necessarily dwarfs rIFG (3 synapses downstream). True scalp frontal-dominance is an **ECD dipole-orientation** phenomenon (frontal dipoles project to frontal electrodes; A1 dipoles tangential) - explicitly deferred from Phase 35 (35-01-D1 "LFP-only gate, ECD->Phase 36"; Fact 6). `ecd_spatial()` exists but needs an `(Nc,3,n)` dipole-gain fixture that does not exist.
  - **Global-negative:** at gain=0 the rIFG difference wave is biphasic - early **+** transient at 64 ms (+1.54e-5) and the canonical **-** MMN deflection at 100 ms (-1.47e-5); the global |peak| is the early positive, so `diff[peak] < 0` is false until gain>=0.75.
- **Resolution:** STOPPED per the plan's deviation rule (do not loosen asserts / fake the figure). Orchestrator selected **Option A** (ship the honest LFP source-space demo now; ECD frontal-topography becomes a separate follow-up phase the orchestrator adds to the roadmap - NOT built here).
- **Fix applied:** (1) keep monotone-attenuation assert; (2) assert the **windowed** (90-120 ms) MMN minimum sign + attenuation instead of the global |peak|; (3) DROP the frontal-dominance assert - **record** the rIFG/A1 ratio + an explicit ECD-deferral note instead. No tuning to fake frontal-dominance.
- **Files modified:** scripts/demo_mmn_precision_sweep.py
- **Verification:** sweep runs green (monotone + windowed-negative both TRUE); rIFG/A1 ratio printed honestly (~5e-4); script prints the ECD-deferral scope note.
- **Committed in:** `dfc77f4` (Task 2 commit)
