ground truth.

These are the key deliverables for Phase 26 success criteria 1-3.

saved results (trained estimator, SBC ranks, comparison metrics).
</objective>

  <action>
    **1. Create `scripts/train_sbi_spectral.py`:**
    - `from __future__ import annotations`
    - Shebang: `#!/usr/bin/env python`
    - Module docstring citing [REF-043] and VBI (eLife 2025) approach
    - Imports: `argparse`, `pathlib.Path`, `time`, `torch`, `pickle`,
      all inference module functions, `make_stable_A_spectral`,
      `default_frequency_grid`

    - CLI arguments via argparse:
      - `--n-regions` (int, default=3)
      - `--n-sims` (int, default=50000) — number of training simulations
      - `--n-sbc` (int, default=200) — number of SBC validation runs
      - `--n-freqs` (int, default=32)
      - `--tr` (float, default=2.0)
      - `--embed-dim` (int, default=64)
      - `--hidden-features` (int, default=128)
      - `--num-transforms` (int, default=5)
      - `--max-epochs` (int, default=200)
      - `--batch-size` (int, default=256)
      - `--output-dir` (str, default="results/sbi_spectral")
      - `--seed` (int, default=42)

    - Main logic:
      (a) Set seed: `torch.manual_seed(args.seed)`
      (b) Create a_mask = torch.ones(N, N) (fully connected)
      (c) Create freqs via `default_frequency_grid(args.tr, args.n_freqs)`
      (d) Create simulator via `make_spectral_dcm_simulator(N, a_mask, freqs)`
      (e) Create prior via `make_spectral_dcm_prior(N)`
      (f) Create embedding net: `CSDEmbeddingNet(obs_dim=2*F*N*N, embed_dim=args.embed_dim)`
      (g) Time the simulation generation + training:
          ```
          t0 = time.time()
          result = train_npe(
              simulator, prior,
              n_simulations=args.n_sims,
              embedding_net=embedding_net,
              density_estimator_kwargs={"hidden_features": args.hidden_features, "num_transforms": args.num_transforms},
              training_kwargs={"training_batch_size": args.batch_size, "max_num_epochs": args.max_epochs},
          )
          train_time = time.time() - t0
          ```
      (h) Build posterior via `build_sbi_posterior(result["inference"], result["estimator"])`
      (i) Run SBC: `sbc_result = run_sbc_validation(posterior, prior, simulator, n_sbc=args.n_sbc)`
      (j) Save outputs to `args.output_dir`:
          - `estimator.pt` — trained estimator state dict via `torch.save`
          - `sbc_ranks.pt` — SBC rank tensor via `torch.save`
          - `training_metadata.pt` — dict with `n_sims`, `train_time`, `n_regions`, `n_freqs`, `seed`, etc. via `torch.save`
      (k) Print summary: training time, n_sims, SBC rank uniformity check
          (Kolmogorov-Smirnov test for uniformity on each parameter's ranks)
      (l) Amortized inference speed test: time 100 posterior.sample() calls
          on a single observation, report mean and std of per-call time.
          Assert mean < 1.0 second (Phase 26 success criterion 2).

    **2. Create `cluster/sbi_spectral_train.sh`:**
    - Follow existing cluster sbatch conventions (see `cluster/` directory)
    - SBATCH directives: `--job-name=sbi_spectral`, `--time=04:00:00`,
      `--mem=32G`, `--cpus-per-task=4`, `--partition=batch` (or whatever
      partition the project uses — check existing sbatch files)
    - Load Python environment (module load + conda/venv activate)
    - Run: `python scripts/train_sbi_spectral.py --n-sims 50000 --n-sbc 200 --output-dir results/sbi_spectral_${SLURM_JOB_ID}`
    - Stdout/stderr to `cluster/logs/sbi_spectral_${SLURM_JOB_ID}.{out,err}`

    **Cluster routing rationale:** 50k simulations at ~1ms each = ~50s (laptop safe).
    But NPE training for 200 epochs on 50k samples + SBC with 200 runs x 1000 posterior
    samples = significant compute. Total estimated: ~30-60 min. Routes to M3 per the
    >3 min threshold.

<task type="auto">
  <name>Task 2: SBI vs SVI comparison script</name>
  <files>
    scripts/compare_sbi_svi.py
  </files>
  <action>
    Create `scripts/compare_sbi_svi.py`:
    - `from __future__ import annotations`
    - Shebang: `#!/usr/bin/env python`
    - Module docstring explaining: "Compare SBI (NPE) posteriors with SVI posteriors
      on synthetic spectral DCM ground truth. Quantifies the amortization gap."
    - Imports: `argparse`, `pathlib.Path`, `time`, `torch`, `pyro`,
      `make_stable_A_spectral`, `simulate_spectral_dcm`,
      `spectral_dcm_model`, `create_guide`, `run_svi`, `extract_posterior_params`,
      `decompose_csd_for_likelihood`, `make_spectral_dcm_simulator`,
      `make_spectral_dcm_prior`, `build_sbi_posterior`,
      `compare_sbi_svi_posteriors`

    - CLI arguments:
      - `--estimator-path` (str, required) — path to saved estimator
      - `--n-test-subjects` (int, default=5) — number of synthetic test subjects
      - `--n-svi-steps` (int, default=500)
      - `--n-posterior-samples` (int, default=5000)
      - `--seed` (int, default=42)
      - `--output-dir` (str, default="results/sbi_vs_svi")

    - Main logic:
      (a) Load trained estimator: `estimator = torch.load(args.estimator_path)`
      (b) Create simulator, prior, posterior (same config as training script, N=3)
      (c) For each test subject (loop over n_test_subjects):
          - Generate ground truth: `A_true = make_stable_A_spectral(3, seed=seed_i)`
          - Simulate: `sim_result = simulate_spectral_dcm(A_true, seed=seed_i)`
          - Get observed CSD: `obs_csd = sim_result["csd"]`
          - Decompose for SBI: `x_obs = decompose_csd_for_likelihood(obs_csd)`
          
          **SBI inference (amortized):**
          - `t0 = time.time()`
          - `sbi_samples = posterior.sample((n_posterior_samples,), x=x_obs)`
          - `sbi_time = time.time() - t0`
          
          **SVI inference (per-subject):**
          - `pyro.clear_param_store()`
          - `guide = create_guide(spectral_dcm_model, init_scale=0.01)`
          - `a_mask = torch.ones(3, 3, dtype=torch.float64)`
          - `freqs = sim_result["freqs"]`
          - `t0 = time.time()`
          - `svi_result = run_svi(spectral_dcm_model, guide, model_args=(obs_csd, freqs, a_mask), n_steps=args.n_svi_steps)`
          - `svi_time = time.time() - t0`
          - Extract SVI samples from guide (sample n_posterior_samples from guide,
            pack into same parameter layout as SBI theta)
          
          **Compare:**
          - `comparison = compare_sbi_svi_posteriors(sbi_samples, svi_samples)`
          - Store: A_true, comparison metrics, sbi_time, svi_time
      
      (d) Aggregate across test subjects:
          - Mean RMSE of posterior means vs ground truth (SBI vs SVI)
          - Mean 95% CI overlap fraction
          - Mean KS statistic
          - Speed ratio: svi_time / sbi_time
      
      (e) Print formatted comparison table:
          ```
          Subject | SBI RMSE | SVI RMSE | SBI Time | SVI Time | CI Overlap
          --------|----------|----------|----------|----------|----------
          1       | 0.xxx    | 0.xxx    | 0.xxxs   | xx.xxxs  | 0.xxx
          ```
      
      (f) Save results to `args.output_dir/comparison_results.pt`

    **Note on SVI sample extraction:** To get SVI samples in the same packed format
    as SBI theta, sample from the guide using `pyro.poutine.trace(guide).get_trace(obs_csd, freqs, a_mask)`,
    extract `A_free`, `noise_a`, `noise_b`, `noise_c` sites, and manually pack
    them into a 1D vector following the same layout as the SBI simulator. Repeat
    n_posterior_samples times and stack. This is the correct way to compare — both
    methods produce samples in the same parameter space.
  </action>

    - Comparison table printed to stdout
    - `ruff check scripts/compare_sbi_svi.py` passes
