Build the SBI infrastructure for spectral DCM: simulator wrapper, prior, embedding
network, diagnostics utilities, and comprehensive tests.

Purpose: This plan creates all the reusable modules that the SBI training pipeline
(Plan 02) will consume. The simulator wrapper bridges the existing spectral DCM
forward model to sbi's expected interface (1D tensor -> 1D tensor). The embedding
network compresses high-dimensional decomposed CSD into learned summary statistics.

an updated `pyproject.toml` with the `sbi` optional dependency.

    **2. Create `src/pyro_dcm/inference/sbi_spectral.py`:**
    - `from __future__ import annotations`
    - Import: `torch`, `sbi.inference.NPE`, `sbi.neural_nets.posterior_nn`,
      `torch.distributions.Independent`, `torch.distributions.Normal`,
      `parameterize_A` from `pyro_dcm.forward_models.neural_state`,
      `spectral_dcm_forward` from `pyro_dcm.forward_models.spectral_transfer`,
      `decompose_csd_for_likelihood` from `pyro_dcm.models.spectral_dcm_model`

    - `make_spectral_dcm_simulator(n_regions, a_mask, freqs)`:
      Returns a closure that takes theta (1D float64 tensor) and returns
      decomposed CSD (1D float64 tensor). Parameter layout (document in docstring):
      `[A_free (N*N), noise_a (2*N), noise_b (2), noise_c (2*N)]`.
      Total param count: `N*N + 4*N + 2`.
      Inside the closure:
      (a) Unpack theta into A_free (N,N), noise_a (2,N), noise_b (2,1), noise_c (2,N)
      (b) Apply a_mask: `A_free = A_free * a_mask`
      (c) Apply `parameterize_A(A_free)` to get A with negative diagonal
      (d) Call `spectral_dcm_forward(A, freqs, noise_a, noise_b, noise_c)`
      (e) Call `decompose_csd_for_likelihood(csd)` to get real 1D vector
      (f) Wrap in `try/except` for NaN: if output contains NaN (from unstable A),
          return `torch.zeros_like(output)` — this is the standard sbi convention
          for handling failed simulations (zeros will have low likelihood under any
          reasonable observation, so NPE learns to avoid those parameter regions).
          Log a warning via `warnings.warn` with the eigenvalue info.
      Cite [REF-043] and [REF-010] in docstring.

    - `make_spectral_dcm_prior(n_regions)`:
      Returns `Independent(Normal(zeros(D), prior_std * ones(D)), 1)` where
      `D = N*N + 4*N + 2` and `prior_std = (1/64)**0.5` matching SPM12.
      Use float64 dtype. Cite SPM12 spm_dcm_fmri_priors.m in docstring.
      NOTE: Do NOT include `csd_noise_scale` in the SBI parameter vector — SBI
      handles observation noise implicitly through the density estimator.

    - `train_npe(simulator, prior, n_simulations=50_000, embedding_net=None, density_estimator_kwargs=None, training_kwargs=None)`:
      (a) Sample `theta = prior.sample((n_simulations,))`
      (b) Simulate: `x = torch.stack([simulator(t) for t in theta])` — include
          progress logging every 10% of simulations
      (c) Build density estimator via `posterior_nn(model="zuko_nsf", embedding_net=embedding_net, **density_estimator_kwargs)`
          with defaults: `hidden_features=128, num_transforms=5`
      (d) Create `NPE(prior=prior, density_estimator=density_estimator)`
      (e) `inference.append_simulations(theta, x)`
      (f) `estimator = inference.train(**training_kwargs)` with defaults:
          `training_batch_size=256, max_num_epochs=200`
      (g) Return dict: `{"estimator": estimator, "inference": inference, "theta": theta, "x": x}`

    - `build_sbi_posterior(inference, estimator)`:
      Calls `inference.build_posterior(estimator)` and returns the posterior object.
      This is a thin wrapper but provides a consistent API and allows future
      customization (e.g., MCMC-based posterior for NLE).

    **3. Create `src/pyro_dcm/inference/sbi_embedding.py`:**
    - `from __future__ import annotations`
    - Import: `torch`, `torch.nn as nn`

    - `class CSDEmbeddingNet(nn.Module)`:
      Compresses decomposed CSD vector `(2*F*N*N,)` into `(embed_dim,)` summary
      statistics. Architecture: 3-layer MLP with ReLU activations.
      ```
      __init__(self, obs_dim, embed_dim=64, hidden_dim=256):
          self.net = nn.Sequential(
              nn.Linear(obs_dim, hidden_dim),
              nn.ReLU(),
              nn.Linear(hidden_dim, hidden_dim),
              nn.ReLU(),
              nn.Linear(hidden_dim, embed_dim),
          )
      forward(self, x): return self.net(x)
      ```
      Document obs_dim calculation in docstring: for N regions and F frequencies,
      `obs_dim = 2 * F * N * N`. Cite VBI (eLife 2025) for learned summary
      statistics approach.

    **4. Create `src/pyro_dcm/inference/sbi_diagnostics.py`:**
    - `from __future__ import annotations`
    - Import: `torch`, `sbi.diagnostics.run_sbc`, `sbi.analysis.plot.sbc_rank_plot`

    - `run_sbc_validation(posterior, prior, simulator, n_sbc=200, n_posterior_samples=1000)`:
      (a) Sample `sbc_theta = prior.sample((n_sbc,))`
      (b) Simulate `sbc_x = torch.stack([simulator(t) for t in sbc_theta])`
      (c) Call `run_sbc(sbc_theta, sbc_x, posterior, num_posterior_samples=n_posterior_samples)`
      (d) Return dict: `{"ranks": ranks, "dap_samples": dap_samples, "n_sbc": n_sbc, "n_posterior_samples": n_posterior_samples}`

    - `compare_sbi_svi_posteriors(sbi_samples, svi_samples, param_names=None)`:
      Takes SBI posterior samples (n_samples, D) and SVI posterior samples
      (n_samples, D), computes per-parameter: mean difference, median difference,
      95% CI overlap fraction, and KS statistic. Returns a dict with keys
      `mean_diff`, `median_diff`, `ci_overlap`, `ks_statistic`, each shape (D,).
      If param_names provided, also returns a summary DataFrame-like dict keyed by
      param name. Use `scipy.stats.ks_2samp` for KS statistic.
