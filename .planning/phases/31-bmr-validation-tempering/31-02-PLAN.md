<objective>
VLBMR-02: validate the analytic BMR approximation against a brute-force model
comparison done with the engine actually under test (VL, not SVI). Do ONE
full-model spectral VL fit, compute analytic BMR ΔF for ~3 single-prune reduced
models, then independently re-fit each reduced model via VL (connection zeroed
in `a_mask`) and read its free energy. Assert RANK agreement (present-edge prune
costs more than absent-edge prune; both methods agree on the worst reduced
model); report Spearman ρ as supporting evidence.

Purpose: Confirms BMR's analytic shortcut tracks an honest refit-based evidence
comparison — but on RANKS only, because absolute ΔF is not comparable between
analytic-Laplace BMR and a refit that re-estimates noise hyperparameters
(Pitfall S3/C1). This is a vertical, independent validation slice — parallel
with 31-01 (Wave 1).

Output: `tests/test_bmr_vs_vl_refit.py` (the `@pytest.mark.vl` agreement test).
Leave the existing SVI-based `tests/test_bmr_vs_elbo.py` untouched as a
historical/secondary cross-check (research Open Question 1: add new VL test,
keep SVI baseline).
</objective>

8. Assertions (the GATE — rank-based, never value-based):
   - Present > absent (BMR side): assert
     `bmr_delta_f["prune_present"] < bmr_delta_f["prune_absent"]`
     (pruning a present edge costs more evidence → more negative ΔF). Message:
     expected present ΔF < absent ΔF, actual both values.
   - Present > absent (brute-force side): assert
     `bruteforce_delta_f["prune_present"] < bruteforce_delta_f["prune_absent"]`,
     same message style.
   - Worst-model agreement: the reduced model with the lowest ΔF (most costly to
     prune) must match between BMR and brute-force VL. Compute
     `bmr_worst = min(bmr_delta_f, key=bmr_delta_f.get)` and
     `bf_worst = min(bruteforce_delta_f, key=bruteforce_delta_f.get)`; assert
     `bmr_worst == bf_worst` (message names both). (Mirror the intent of
     `test_bmr_vs_elbo.py:360-375`.)
   - Do NOT assert equality of ΔF magnitudes anywhere (Pitfall S3/C1).
