    ```python
    def simulate_latent_circuit(

        n_driving_inputs: int | None = None,
    ) -> dict[str, Any]:
    ```

    Key implementation details:
    - Initial state: `torch.zeros(N, dtype=dtype)` directly (NOT `make_initial_state` which returns 5N zeros -- see Pitfall 2 in RESEARCH.md).
    - Construct `CoupledDCMSystem(A, C, input_fn, hemodynamic=False, B=B_stacked, n_driving_inputs=n_driving_inputs)`.
    - ODE integration via `integrate_ode(system, y0, t_eval, method=solver, step_size=dt)`.
    - Noise: Gaussian noise added AFTER ODE integration, scaled to achieve specified SNR. SNR = std(signal) / std(noise), computed per-region and averaged.
    - Reuse `_normalize_B_list` helper from task_simulator.py (import it, or reimplement the same logic).

    - `'B_list'`: ground-truth B_list (None in linear mode)

    - `'noise_std'`: scalar noise standard deviation used
    - `'SNR'`: achieved SNR
