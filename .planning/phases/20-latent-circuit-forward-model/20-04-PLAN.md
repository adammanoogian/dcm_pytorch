  <action>
    Create `benchmarks/latent_circuit_metrics.py` that provides latent-circuit-specific metrics and an acceptance gate aggregator.

    **Import reused functions from bilinear_metrics.py:**
    - `compute_b_rmse_magnitude` (RECOV-04 pattern)
    - `compute_sign_recovery_nonzero` (RECOV-05 pattern)
    - `compute_coverage_of_zero` (RECOV-06 pattern)
    - `compute_shrinkage` (RECOV-07 pattern)

    **New functions:**

    1. `compute_trajectory_r_squared(predicted, observed)`:
       - predicted: (T, N) tensor, observed: (T, N) tensor
       - Compute per-region R-squared: `1 - SS_res / SS_tot` where `SS_res = sum((obs - pred)^2, dim=0)`, `SS_tot = sum((obs - obs.mean(dim=0))^2, dim=0)`.
       - Return mean R-squared across regions (float).
       - Clamp SS_tot to min 1e-12 to avoid division by zero.

    2. `compute_elbo_model_selection(elbo_dict)`:
       - elbo_dict: `{N: float}` mapping candidate region count to best ELBO (lower is better, since ELBO is negative loss).
       - Wait -- Pyro run_svi returns loss (negative ELBO), so LOWER loss = BETTER. The "best model" has the LOWEST loss.
       - Return dict with: `selected_n` (int), `elbos` (copy of input), `correct` (bool, if true_n provided).
       - Accept optional `true_n: int | None` parameter. If provided, set `correct = (selected_n == true_n)`.

    3. `compute_latent_circuit_acceptance_gates(runner_results, *, thresholds=None)`:
       - runner_results: list of per-seed dicts from the runner, each containing:
         - `a_rmse`: float
         - `b_rmse`: float (magnitude-masked)
         - `sign_recovery`: float
         - `ci_coverage_95`: float
         - `trajectory_r_squared`: float
         - `shrinkage_A`: float, `shrinkage_B`: float
       - thresholds: optional dict overriding default thresholds.
       - Default thresholds (to be empirically calibrated in Plan 20-05):
         - `a_rmse_threshold`: 0.15 (provisional -- direct observation should recover better than BOLD)
         - `b_rmse_threshold`: 0.20 (same as RECOV-04)
         - `sign_recovery_threshold`: 0.80 (same as RECOV-05)
         - `ci_coverage_threshold`: 0.85 (same as RECOV-06)
         - `trajectory_r_squared_threshold`: 0.95 (correctly-specified model, SYNTH-02)
       - Compute per-seed pass/fail, then aggregate: a gate passes if the MEDIAN across seeds meets threshold.
       - Return dict with per-gate pass/fail, per-seed values, medians, and overall pass/fail.

    4. `compute_coverage_multi_level(samples, true_value, levels)`:
       - Compute CI coverage at multiple credible interval levels (50%, 75%, 90%, 95%).
       - samples: (n_samples, ...) tensor, true_value: (...) tensor, levels: list of floats.
       - For each level, compute lower/upper quantiles, check if true_value falls within.
       - Return dict: `{level: coverage_fraction}`.

    Module-level threshold constants with docstrings explaining they are provisional and subject to recalibration in Plan 20-05.
  </action>

    **benchmarks/runners/latent_circuit_recovery.py:**

    Create a runner following the `task_bilinear.py` pattern. Main function:

    ```python
    def run_latent_circuit_recovery(
        config: BenchmarkConfig,
        *,
        n_regions: int = 4,
        n_modulators: int = 1,
        n_restarts: int = 10,
        init_scale: float = 0.1,
        lc_a_prior_var: float | None = None,
        lc_b_prior_var: float | None = None,
    ) -> dict[str, Any]:
    ```

    Implementation:
    1. **Ground truth setup**: N=4 generic bilinear system.
       - A: `make_stable_latent_circuit_A(n_regions, density=0.5, seed=0, self_inhibition=0.5)` for the base, then add directed connections: A[0,1]=0.2, A[1,2]=0.15, A[2,3]=0.1 (descending chain, stable).
       - B: J=1 modulator. B[1,0]=0.4, B[2,1]=0.3, B[3,2]=0.2 (directed chain, descending magnitudes). Rest zero.
       - C: single driving input to region 0, amplitude 1.0.
       - Verify stability: `max Re(eig(A + B @ 1.0)) < -0.05` (safe margin). If not, scale B down.
       - Stimulus: block design -- 5 blocks of 10s ON + 10s OFF over 100s. Modulator: 3 epochs of 8s at t=[10, 40, 70].
       - Duration: 100s, dt=0.01.

    2. **Per-seed loop** (n_seeds from config):
       a. Generate data via `simulate_latent_circuit(A, C, stimulus, duration, dt, SNR=10, seed=base_seed+i, B_list=B, stimulus_mod=stim_mod)`.
       b. **Train/test split**: Use first 80% of time points for fitting, last 20% for trajectory R-squared evaluation (held-out per SYNTH-02).
       c. Construct model args: (observed_trajectories_train, stimulus, a_mask, c_mask, t_eval_train, dt).
       d. Create guide_factory via `functools.partial(create_guide, latent_circuit_dcm_model, guide_type="auto_normal", init_scale=init_scale)`.
       e. Run `run_svi(latent_circuit_dcm_model, guide_factory(), model_args, num_steps=config.get("n_svi_steps", 1000), n_restarts=n_restarts, guide_factory=guide_factory, model_kwargs={"b_masks": b_masks, "stim_mod": stim_mod})`.
       f. Extract posterior via `extract_posterior_params(guide, model_args, latent_circuit_dcm_model)`.
       g. Compute per-seed metrics: A-RMSE, B-RMSE (magnitude-masked), sign recovery, CI coverage (95%), shrinkage, trajectory R-squared (on held-out test segment using posterior mean parameters + ODE forward pass).
       h. Store per-seed results.

    3. **Seed-pool rejection** (from task_bilinear.py pattern): Before fitting, verify simulated data has no NaN. If NaN, skip seed and increment (up to 2x pool multiplier).

    4. If `lc_a_prior_var` or `lc_b_prior_var` are provided, temporarily monkey-patch the module constants before fitting and restore after. This enables the calibration sweep (Plan 20-05) to test different prior values without code changes.

    5. Return dict with:
       - `per_seed_results`: list of per-seed metric dicts
       - `ground_truth`: {A, B_list, C}
       - `config`: runner config summary
       - `aggregate`: medians across seeds for each metric
