    **Step 3: Create ELBO model selection script.**

    `cluster/scripts/lc_elbo_model_selection.py`:

    With C_obs=I (v0.6.0), model selection tests whether ELBO correctly identifies the true number of dynamically coupled dimensions. The approach:
    - Generate 4-dim ground-truth data from the N=4 bilinear system.
    - For each candidate N in {2, 3, 4, 5, 6}:
      - N < 4 (underfitting): Fit to the first N dimensions only (dims [0..N-1]). This discards coupling information, so ELBO should be worse than N=4.
      - N = 4 (correct): Fit to all 4 dimensions. ELBO should be best here.
      - N > 4 (overfitting): Augment data with (N-4) noise-only columns (zero-mean Gaussian, same noise_std as the real data). Extra parameters penalize ELBO.
    - Use 3 seeds per candidate N, 5 restarts per seed (lighter than full acceptance). Record best ELBO per candidate N (mean across seeds).
    - Call `compute_elbo_model_selection(elbo_dict, true_n=4)`.
    - Print results table: candidate N, mean ELBO, selected.
    - Save to `cluster/results/lc_elbo_selection_{job_id}.json`.
