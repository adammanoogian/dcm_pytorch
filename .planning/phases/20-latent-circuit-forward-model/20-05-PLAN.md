    **Step 3: Create ELBO model selection script.**

    `cluster/scripts/lc_elbo_model_selection.py`:
    - For each candidate N in {2, 3, 4, 5, 6}:
      - Generate synthetic data from the N=4 ground truth (same as acceptance run).
      - Fit latent_circuit_dcm_model with a_mask/c_mask/b_masks sized for candidate N (when candidate N < true N, use first N dimensions; when candidate N > true N, pad with zero connections).
      - Actually, the ELBO model selection tests whether the ELBO correctly identifies the true dimensionality. The "candidate" models have different numbers of latent dimensions (regions), NOT subsets of the true model.
      - For N < 4: fit to first N principal components of the 4-dim trajectory (project down via PCA). For N > 4: pad the trajectory with zeros and fit. Actually this is wrong -- the model selection is about choosing the right number of nodes for the same data.
      - Better approach: For each candidate N in {2, 3, 4, 5, 6}, fit a model with N regions to the SAME 4-dimensional observed data, but where the model internally has N latent states and a (N, 4) observation matrix mapping latents to observations. BUT we fixed C_obs=I for v0.6.0, so this doesn't work.
      - Correct interpretation: Generate separate ground-truth datasets for each candidate N? No, the point is to identify the TRUE N from data.
      - With C_obs=I, the data IS the latent state. So the model with N regions fits N-dimensional data. For ELBO comparison: generate 4-dim data, then for N=2 fit only first 2 dims, for N=4 fit all 4, for N=6 the data only has 4 dims so this doesn't work with C_obs=I.
      - Resolution: With C_obs=I, model selection means: "given these trajectories, how many independent latent dimensions are dynamically coupled?" For N < true: fit N-dim subset (underfitting -- misses coupling). For N > true: fit N-dim data padded with noise dims (overfitting -- extra parameters). The ELBO should prefer N=4 because it balances fit quality vs parameter count.
      - Implementation: Generate 4-dim data. For N=2: fit to dims [0,1] only. For N=3: fit to dims [0,1,2]. For N=4: fit to all. For N=5: augment data with a 5th noise-only column. For N=6: augment with 2 noise-only columns.
      - Use 3 seeds per candidate N, 5 restarts per seed (lighter than full acceptance). Record best ELBO per candidate N.

    - Print results table: candidate N, mean ELBO, selected.
