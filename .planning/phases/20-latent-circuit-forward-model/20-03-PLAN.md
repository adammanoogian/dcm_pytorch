    **Function signature:**
    ```python
    def direct_observation(
        x: torch.Tensor,
        C_obs: torch.Tensor,
        noise_prec: torch.Tensor,
    ) -> tuple[torch.Tensor, torch.Tensor]:
    ```

    **Implementation:**
    - Computes `y_mean = C_obs @ x` when `C_obs` is not identity. When `C_obs` is a square identity matrix, this reduces to `y_mean = x`.
    - Computes `noise_std = (1.0 / noise_prec).sqrt()`.
    - Returns `(y_mean, noise_std)` -- the predicted observation mean and noise standard deviation.
    - The function does NOT sample or call pyro.sample. It is a pure deterministic computation. The Pyro sampling happens in the model function that calls this.
    - x shape: `(T, N)` or `(N,)`. C_obs shape: `(P, N)` where P is the observation dimension. When C_obs=I, P=N.
    - noise_prec shape: scalar or `(P,)`.
    - Use `torch.linalg.solve` or matrix multiply as appropriate. For C_obs @ x with x shape (T, N), compute `(C_obs @ x.T).T` to get (T, P), or equivalently `x @ C_obs.T`.

    **Docstring:** NumPy-style. Cite OBS-02 from REQUIREMENTS-v0.6.0.md. Document that for v0.6.0, C_obs is always identity (P=N), but the function supports arbitrary C_obs for future learned projection (v0.7.0+, MODEL-04).

    **Module docstring:** Explain this module provides the observation equation for latent circuit DCM, mapping neural states to observations.

    **__init__.py update:** Add `direct_observation` to `forward_models/__init__.py` imports and `__all__`.
  </action>

    """Prior variance on B_free elements for latent circuit DCM.

    Matches task-DCM B_PRIOR_VARIANCE as initial value; subject to
    recalibration. The Phase 16.1 lesson showed init_scale x prior_var
    interaction is the primary failure mode for B recovery.

    **Function signature:**
    ```python
    def latent_circuit_dcm_model(
        observed_trajectories: torch.Tensor,  # (T, N)
        stimulus: PiecewiseConstantInput,
        a_mask: torch.Tensor,
        c_mask: torch.Tensor,
        t_eval: torch.Tensor,
        dt: float = 0.01,
        *,
        b_masks: list[torch.Tensor] | None = None,
        stim_mod: PiecewiseConstantInput | None = None,
    ) -> None:
    ```

    Key differences from task_dcm_model:
    1. **No TR parameter** -- no downsampling. The observation time grid equals the integration time grid.
    2. **dt default = 0.01** (not 0.5) -- direct observation needs finer integration to match trajectory resolution.
    3. **Prior constants**: Use LC_A_PRIOR_VARIANCE (not 1/64) and LC_B_PRIOR_VARIANCE (not B_PRIOR_VARIANCE).
    4. **No hemodynamic parameters**: No BalloonWindkessel, no BOLD, no hemo_params.
    5. **CoupledDCMSystem(hemodynamic=False)**: State is N-dim, solution is (T, N).
    6. **Initial state**: `y0 = torch.zeros(N, dtype=torch.float64)` directly (NOT make_initial_state which returns 5N).
    7. **ODE method**: Use `method="rk4"` for SVI (predictable computation graph).
    8. **No BOLD extraction**: Solution IS the predicted trajectories.
    9. **No TR downsampling**: `predicted = solution[:T]` (trim to match observed length).
    10. **Observation via direct_observation**: Import and call `direct_observation(predicted, C_obs, noise_prec)` from `latent_observation.py` to compute y_mean and noise_std. For v0.6.0, construct `C_obs = torch.eye(N, dtype=torch.float64)` inside the model. The likelihood is `pyro.sample("obs", dist.Normal(y_mean, noise_std).to_event(2), obs=observed_trajectories)`.
    11. **Scalar noise_prec**: Single `noise_prec ~ Gamma(1, 1)` shared across all N dimensions (RESEARCH recommendation).
    12. **NaN guard**: Same pattern as task_dcm_model (detach + zero-fill on NaN/Inf).

    **B sampling**: Use the EXACT same pattern as task_dcm_model lines 293-337:
    - Validate with _validate_bilinear_args (copy the helper or import from task_dcm_model).
    - For loop over b_masks: `pyro.sample(f"B_free_{j}", ...)` with LC_B_PRIOR_VARIANCE.
    - Stack, parameterize_B, pyro.deterministic("B", ...).
    - merge_piecewise_inputs for drive + mod.

    **Sample site naming**: Use the SAME names as task_dcm_model: "A_free", "C", "B_free_0", "B_free_1", ..., "noise_prec", "obs". Deterministic sites: "A", "B", "predicted_trajectories" (instead of "predicted_bold").

    **Docstring**: NumPy-style with full parameter documentation, equation references, and notes explaining differences from task_dcm_model. Cite David et al. 2006 (EEG/MEG DCM precedent for direct observation without hemodynamics) and note that C_obs=I is fixed for v0.6.0 with learned C_obs deferred to v0.7.0+ (MODEL-04).

    **__init__.py update**: Add `latent_circuit_dcm_model` to imports from `latent_circuit_dcm_model` module and to `__all__`.
