  <action>
    Add two new parameters to `run_svi()`:
    - `n_restarts: int = 1` -- number of independent SVI runs. Default 1 preserves backward compatibility.
    - `guide_factory: Callable[[], Any] | None = None` -- callable that returns a fresh guide instance. Required when `n_restarts > 1`. When None and `n_restarts > 1`, raise ValueError explaining that guide_factory is needed for safe re-initialization.

    Implementation structure:

    When `n_restarts <= 1`: Execute the EXISTING single-run code path EXACTLY as-is. No structural changes. Return the same dict: `{"losses", "final_loss", "num_steps"}` (plus optional `"guide"` for auto_laplace). Do NOT add `"all_restarts"` or `"n_restarts"` keys in this path -- backward compat is paramount.

    When `n_restarts > 1`:
    1. Validate guide_factory is not None (raise ValueError if it is).
    2. Outer loop: `for restart_idx in range(n_restarts):`
       a. Call `pyro.clear_param_store()`.
       b. Create fresh guide: `current_guide = guide_factory()`.
       c. Run the SVI loop (same optimizer construction, ELBO, step loop as existing code).
       d. Wrap `svi.step()` in try/except RuntimeError to catch NaN ELBO -- on NaN, record `final_loss=float('inf')` for this restart and continue to next restart (don't abort the entire multi-start).
       e. Store result dict: `{"losses": losses, "final_loss": losses[-1], "restart": restart_idx, "num_steps": num_steps}`.
    3. Select best restart by minimum `final_loss` (skip any with `final_loss=inf`).
    4. If ALL restarts produced inf (all NaN), raise RuntimeError with descriptive message.
    5. Return dict with:
       - `"losses"`: losses from best restart
       - `"final_loss"`: best final loss
       - `"num_steps"`: num_steps from best restart
       - `"n_restarts"`: n_restarts
       - `"best_restart_idx"`: index of best restart
       - `"all_restarts"`: list of per-restart result dicts
       - `"guide"`: (only for auto_laplace) post-processed guide from best restart

    For the multi-restart path, the best guide's param store state needs to be preserved. After selecting the best restart, re-run the best guide's factory and reload its params. Alternative (simpler): save the param_store state dict after each restart and restore the best one at the end. Use `pyro.get_param_store().get_state()` / `pyro.get_param_store().set_state()`.

    Actually, the SIMPLEST correct approach: after finding the best restart index, clear param store, re-create guide from factory, and re-run the best restart (using the same seed if deterministic). But this doubles compute for the best run.

    Better approach: save `pyro.get_param_store().get_state()` after each restart's SVI loop completes. After all restarts, restore the best one's state: `pyro.clear_param_store(); pyro.get_param_store().set_state(best_state)`. This way the caller can immediately use `extract_posterior_params` on the guide_factory()-created guide with the restored param store.

    Add the best guide's param store state restoration AND return `"guide_factory"` in the result so callers can create a guide matching the restored params.

    Update the run_svi docstring to document the new parameters, their interaction, and the return dict extension for n_restarts > 1.

    Logging: use `logging.getLogger("pyro_dcm.svi")` to log `INFO` messages: "Multi-start SVI: restart {i+1}/{n_restarts}, final ELBO: {loss:.2f}" after each restart, and "Multi-start SVI: best restart {idx} with ELBO {loss:.2f}" at the end.

    Do NOT modify the `__init__.py` re-exports -- `run_svi` is already exported.
  </action>
