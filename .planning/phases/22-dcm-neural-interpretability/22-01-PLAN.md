<objective>
Adapt the spectral DCM infrastructure for MEG electrophysiology frequencies.

Purpose: The existing spectral DCM was built for fMRI (0.008-0.25 Hz). MEG source-space
data operates at 1-100 Hz. Three adaptations are needed: (1) frequency grid for MEG,
(2) parameterized eigenvalue clamp threshold (fMRI uses -1/32 which is too aggressive
for MEG), (3) prior scale override for A_free (fMRI uses 1/64 variance which may be
wrong for neural-timescale connectivity). All changes must preserve backward compatibility
for fMRI callers.

Output: Modified spectral_transfer.py and spectral_dcm_model.py with backward-compatible
MEG support, plus a test file validating MEG-specific behavior.
</objective>
