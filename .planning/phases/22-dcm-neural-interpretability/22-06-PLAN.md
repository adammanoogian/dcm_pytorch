<objective>
Execute the full perturbation validation on M3 and analyze results.

Purpose: This is the culmination of Phase 22 -- running the perturbation experiment at
full scale and comparing raw-CSD DCM vs latent-CSD DCM. The key question is: does fitting
spectral DCM to the autoencoder's latent dynamics detect connectivity perturbations that
raw DCM also detects? Better? Worse? Differently?

The validation script runs the perturbation experiment twice:
Path A: Fit spectral DCM directly to raw CSD from simulated timeseries
Path B: Fit spectral DCM to latent CSD from autoencoder representations

Comparing perturbation detection across paths reveals what the autoencoder adds or loses.

Output: Full-scale results + comparison figures + scientific interpretation.
</objective>

  <action>
1. Create `scripts/22_run_full_validation.py`:
   - argparse CLI: --output-dir (root output), --seed (int, default=42),
     --submit-cluster (bool flag)

   - Path A (raw CSD baseline):
     * Generate timeseries from A_baseline
     * Compute raw CSD directly from timeseries (no autoencoder)
     * Fit spectral DCM to raw CSD
     * For each perturbation condition:
       - Generate perturbed timeseries, compute raw CSD, fit DCM
       - Compare raw DCM posterior to baseline

   - Path B (latent CSD -- uses autoencoder):
     * Same data, but passed through trained autoencoder first
     * This is the perturbation_experiment.py flow

   - Comparison:
     * For each perturbation condition, compare:
       - Raw DCM z-score for the perturbed connection
       - Latent DCM z-score for the perturbed connection
     * Save comparison to output-dir/raw_vs_latent_comparison.npz

   - Submit to M3 cluster for production-scale execution (1000 SVI steps,
     10 restarts, 200 training samples, 50 eval samples)

2. The orchestrator can call the perturbation experiment script via subprocess
