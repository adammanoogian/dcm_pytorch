<task type="auto">
  <name>Task 1: Create pipeline scripts 22_preprocess through 22_extract</name>
  <files>scripts/22_preprocess_camcan.py, scripts/22_train_autoencoder.py, scripts/22_extract_latent_dynamics.py</files>
  <action>
1. Create `scripts/22_preprocess_camcan.py`:
   - argparse CLI: --data-dir (path to Cam-CAN MEG), --output-dir (output path),
     --n-subjects (int, default=50), --roi-names (optional list, defaults to
     DEFAULT_ROI_NAMES), --subjects-dir (FreeSurfer subjects_dir, optional)
   - Scans data-dir for sub-CC*/meg/*_task-smt_meg.fif files
   - For each subject (up to n_subjects):
     * Calls load_and_preprocess_subject from camcan_loader
     * Saves ROI timeseries to output-dir/sub-CC{id}_roi_ts.npz
       (keys: timeseries, times, roi_names, sfreq)
   - Also computes and saves raw CSD for each subject using epochs_to_csd from mne_loader
     (or compute_empirical_csd from csd_computation.py on the averaged timeseries)
   - Saves aggregated raw CSD (averaged across subjects) to output-dir/raw_csd_group.npz
   - Prints summary: N subjects processed, T timepoints, N_roi ROIs

2. Create `scripts/22_train_autoencoder.py`:
   - argparse CLI: --data-dir (preprocessed .npz files), --output-dir (checkpoints),
     --n-latent (int, default=6, matches N_roi for interpretability per research),
     --hidden-size (int, default=64), --n-layers (int, default=1),
     --n-epochs (int, default=100), --batch-size (int, default=64),
     --lr (float, default=1e-3), --patience (int, default=15),
     --device (str, default="cuda" if available else "cpu"),
     --window-size (int, default=500, number of timepoints per training window),
     --window-stride (int, default=250, stride between windows for overlap)
   - Loads all *_roi_ts.npz files from data-dir
   - Segments each subject's timeseries into windows of window-size with stride window-stride
   - Splits into train (80%) and val (20%) sets
   - Creates DataLoaders with batch_size
   - Creates MEGAutoencoder with specified hyperparameters
   - Creates AutoencoderTrainer with checkpoint_dir=output-dir
   - Trains with early stopping
   - Saves: best model checkpoint, training curves (JSON), final reconstruction examples
   - Prints: final train/val loss, best epoch, reconstruction MSE

3. Create `scripts/22_extract_latent_dynamics.py`:
   - argparse CLI: --data-dir (preprocessed .npz files), --checkpoint (path to model .pt),
     --output-dir (output path), --n-latent (int, must match checkpoint),
     --device (str, default="cpu")
   - Loads trained MEGAutoencoder from checkpoint
   - For each subject's *_roi_ts.npz:
     * Loads ROI timeseries
     * Calls extract_latent_trajectories
     * Saves latent trajectories to output-dir/sub-CC{id}_latent.npz
   - Computes latent CSD per subject using compute_latent_csd
   - Saves aggregated latent CSD (averaged across subjects) to output-dir/latent_csd_group.npz
   - Also saves per-subject latent CSD for group-level analysis
   - Computes reconstruction quality: MSE between original and reconstructed timeseries
   - Prints: mean reconstruction MSE, latent CSD shape, frequency range

All scripts: `from __future__ import annotations`, NumPy docstrings on main(),
`if __name__ == "__main__": main()` pattern, full imports.

<task type="auto">
  <name>Task 2: Create DCM fitting, comparison scripts, and cluster sbatch files</name>
  <files>scripts/22_fit_spectral_dcm.py, scripts/22_compare_connectivity.py, cluster/sbatch/22_train_autoencoder.sbatch, cluster/sbatch/22_fit_dcm.sbatch</files>
  <action>
1. Create `scripts/22_fit_spectral_dcm.py`:
   - argparse CLI: --raw-csd (path to raw_csd_group.npz), --latent-csd (path to
     latent_csd_group.npz), --output-dir (output path), --n-restarts (int, default=10),
     --n-steps (int, default=2000), --lr (float, default=0.01),
     --prior-a-var (float, default=1/16, MEG-scale per research),
     --eig-clamp (float, default=-1.0, MEG-scale per research)
   - Path A (raw ROI CSD):
     * Loads raw CSD from .npz, converts to torch tensors
     * Creates a_mask = torch.ones(N_roi, N_roi)
     * Calls spectral_dcm_model with prior_a_var and eig_clamp overrides
     * Uses create_guide + run_svi with n_restarts
     * Extracts posterior A via extract_posterior_params
     * Saves to output-dir/posterior_raw.npz (A_mean, A_std, losses, final_loss)
   - Path B (latent CSD):
     * Same process but on latent CSD
     * Saves to output-dir/posterior_latent.npz
   - Prints: Path A final ELBO, Path B final ELBO, A_raw shape, A_latent shape

2. Create `scripts/22_compare_connectivity.py`:
   - argparse CLI: --raw-posterior (path), --latent-posterior (path),
     --output-dir (figures), --roi-names (optional list for labels)
   - Loads both posterior .npz files
   - Generates comparison figures (matplotlib):
     a. Side-by-side A matrix heatmaps (raw vs latent), annotated with ROI names
     b. Posterior A element scatter: A_raw vs A_latent (off-diagonal elements)
     c. Difference matrix: A_latent - A_raw (where do they diverge?)
     d. Diagonal elements comparison (self-connections)
     e. Convergence plot: ELBO curves for both paths
   - Saves figures to output-dir/
   - Prints summary statistics: correlation between A_raw and A_latent off-diagonal,
     mean absolute difference, which connections are strongest in each

3. Create `cluster/sbatch/22_train_autoencoder.sbatch`:
   - M3 cluster sbatch header:
     * --job-name=ae_train_22
     * --time=04:00:00 (4 hours, conservative for LSTM-AE)
     * --mem=32G
     * --gres=gpu:1 (single GPU)
     * --partition=gpu (M3 GPU partition)
   - Loads conda/module environment
   - Runs: python scripts/22_train_autoencoder.py --data-dir $DATA_DIR --output-dir $OUTPUT_DIR
     --device cuda --n-epochs 200 --patience 20

4. Create `cluster/sbatch/22_fit_dcm.sbatch`:
   - M3 cluster sbatch header:
     * --job-name=dcm_fit_22
     * --time=08:00:00 (8 hours for multi-restart SVI on 2 paths)
     * --mem=32G
     * --cpus-per-task=4
     * No GPU (spectral DCM SVI is CPU-bound)
   - Runs: python scripts/22_fit_spectral_dcm.py --raw-csd $RAW_CSD --latent-csd $LATENT_CSD
     --output-dir $OUTPUT_DIR --n-restarts 10 --n-steps 2000

All scripts: `from __future__ import annotations`, argparse, ruff clean.
Sbatch files follow existing rnn_train_array.sbatch conventions.
