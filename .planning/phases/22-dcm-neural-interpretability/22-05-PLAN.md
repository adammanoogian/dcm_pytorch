<objective>
Create the perturbation experiment framework that validates whether changes to ground-truth
connectivity are detectable through the latent DCM pipeline.

Purpose: This is the core validation experiment for Phase 22. We generate timeseries from
a known A_baseline, train an autoencoder, fit DCM to latent CSD, then perturb specific
connections in A (strengthen, weaken, remove), regenerate timeseries from A_perturbed,
pass through the SAME trained autoencoder, fit DCM to the new latent CSD, and check
whether the perturbation appears in the DCM posterior. If the pipeline can detect known
perturbations, it validates DCM as an interpretability tool for learned representations.

Perturbation design:
- Target connections: M1_lh -> S1_lh (strong), PMC_lh -> M1_lh (medium), A1_lh -> M1_lh (weak)
- Perturbation types: +50% (strengthen), -50% (weaken), set to 0 (remove)
- Each condition: generate 50 samples, extract latents, fit DCM (300 steps, 5 restarts)
- Metric: |delta_A_posterior[i,j]| for the perturbed connection vs unperturbed connections
  (effect size / signal-to-noise)

Output: Perturbation experiment script, analysis script, cluster sbatch, and a smoke test.
</objective>

  <name>Task 1: Create perturbation experiment script and smoke test</name>
  <files>scripts/22_perturbation_experiment.py, tests/test_perturbation_recovery.py</files>
  <action>
1. Create `scripts/22_perturbation_experiment.py`:
   - argparse CLI:
     * --output-dir (results path)
     * --n-train (int, default=200, training samples for autoencoder)
     * --n-eval (int, default=50, evaluation samples per perturbation condition)
     * --n-latent-multiplier (int, default=2, n_latent = multiplier * n_roi)
     * --hidden-size (int, default=64, LSTM hidden)
     * --ae-epochs (int, default=100, autoencoder training epochs)
     * --svi-steps (int, default=500, spectral DCM SVI steps)
     * --n-restarts (int, default=5, SVI restarts)
     * --seed (int, default=42)

   - Step 1: Generate baseline dataset
     * A_base = make_sensorimotor_A(seed=seed)
     * Generate training data: simulate_meg_timeseries(A_base, n_samples=n_train, ...)
     * Generate baseline eval data: simulate_meg_timeseries(A_base, n_samples=n_eval, seed=seed+1000)

   - Step 2: Train autoencoder on baseline data
     * MEGAutoencoder(n_roi=10, n_latent=20, hidden_size=hidden_size)
     * Train with AutoencoderTrainer for ae_epochs
     * Save checkpoint

   - Step 3: Extract baseline latent CSD and fit baseline DCM
     * Extract latent trajectories from baseline eval data
     * Compute latent CSD (averaged over samples)
     * Fit spectral DCM (svi_steps, n_restarts, prior_a_var=1/16, eig_clamp=-1.0)
     * Save baseline posterior A

   - Step 4: Perturbation sweep
     * Define perturbation conditions (list of dicts):
       - {"name": "M1_S1_strengthen", "i": 0, "j": 2, "factor": 1.5}
       - {"name": "M1_S1_weaken", "i": 0, "j": 2, "factor": 0.5}
       - {"name": "M1_S1_remove", "i": 0, "j": 2, "factor": 0.0}
       - {"name": "PMC_M1_strengthen", "i": 4, "j": 0, "factor": 1.5}
       - {"name": "PMC_M1_weaken", "i": 4, "j": 0, "factor": 0.5}
       - {"name": "PMC_M1_remove", "i": 4, "j": 0, "factor": 0.0}
       - {"name": "A1_M1_strengthen", "i": 8, "j": 0, "factor": 1.5}
       - {"name": "A1_M1_remove", "i": 8, "j": 0, "factor": 0.0}
       - {"name": "bilateral_M1_strengthen", "i": 0, "j": 1, "factor": 2.0}
     * For each condition:
       - A_perturbed = A_base.clone(); A_perturbed[i, j] *= factor
       - Generate eval data from A_perturbed (SAME autoencoder, just new data)
       - Extract latent trajectories using the TRAINED autoencoder (not retrained)
       - Compute latent CSD
       - Fit spectral DCM
       - Compute delta_A = A_posterior_perturbed - A_posterior_baseline
       - Save results: condition name, delta_A, full posterior, ground truth delta

   - Step 5: Save all results to output-dir/perturbation_results.npz

   Use `from __future__ import annotations`, argparse, `if __name__ == "__main__": main()`

2. Create tests/test_perturbation_recovery.py (smoke test):
   - test_perturbation_changes_posterior: Mini version (3 regions, 50 train samples,
     20 eval, 100 SVI steps, 1 restart). Perturb one strong connection by 2x.
     Verify: |delta_A_posterior[perturbed_ij]| > median(|delta_A_posterior[other_ij]|)
     (the perturbed connection moves more than the median unperturbed connection)
   - test_no_perturbation_stable_posterior: Run baseline twice with different eval samples.
     Verify: max(|delta_A|) is small (< 0.5, no false perturbation detected)
   - Mark both @pytest.mark.slow
  </action>

- `ruff check scripts/22_perturbation_experiment.py tests/test_perturbation_recovery.py`
  </verify>
