<objective>
Create the LSTM autoencoder module for MEG ROI timeseries and its training infrastructure,
with an overcomplete latent space (n_latent = 2 * n_roi by default) and optional spectral
consistency loss.

Purpose: The temporal model is the deep learning component whose latent dynamics will be
analyzed by DCM. An LSTM autoencoder maps multivariate ROI timeseries (T, N_roi) to an
overcomplete latent representation (T, N_latent), where N_latent = 2 * N_roi. The
overcomplete representation avoids a bottleneck that might discard spectrally relevant
information. The trainer supports an optional spectral consistency loss that penalizes
CSD differences between input and reconstruction, ensuring the latent space preserves
cross-spectral structure needed for downstream spectral DCM.

Output: New `src/pyro_dcm/neural_data_models/` subpackage containing MEGAutoencoder
(nn.Module) and AutoencoderTrainer, plus comprehensive unit tests.
</objective>

   class MEGAutoencoder(nn.Module):
   - Parameters: n_roi (int), n_latent (int | None = None, defaults to 2 * n_roi),
     hidden_size (int, default=64), n_layers (int, default=1),
     dropout (float, default=0.0)
   - If n_latent is None, set self.n_latent = 2 * n_roi
   - Architecture:
     * encoder_lstm: nn.LSTM(n_roi, hidden_size, n_layers, batch_first=True, dropout=dropout)
     * encoder_fc: nn.Linear(hidden_size, n_latent)
     * decoder_fc: nn.Linear(n_latent, hidden_size)
     * decoder_lstm: nn.LSTM(hidden_size, n_roi, n_layers, batch_first=True, dropout=dropout)
   - Methods:
     * encode(x: Tensor) -> Tensor: (batch, T, N_roi) -> (batch, T, N_latent)
       Passes x through encoder_lstm, applies encoder_fc to all timesteps.
     * decode(latent: Tensor) -> Tensor: (batch, T, N_latent) -> (batch, T, N_roi)
       Passes latent through decoder_fc, then decoder_lstm.
     * forward(x: Tensor) -> tuple[Tensor, Tensor]: Returns (reconstruction, latent)
   - Store n_roi, n_latent, hidden_size, n_layers as attributes.
   - Use `from __future__ import annotations` at top.
   - NumPy-style docstring on class and all methods with full shape annotations.
   - Type hints: Python 3.10+ syntax.

IMPORTANT: The encoder produces a latent trajectory at EVERY timestep (not just final
hidden state), because we need continuous latent dynamics for CSD computation.

   class AutoencoderTrainer:
   - __init__(model: MEGAutoencoder, *, lr: float = 1e-3,
     weight_decay: float = 0.0, device: str = "cpu",
     checkpoint_dir: Path | None = None,
     spectral_weight: float = 0.0, sfreq: float = 250.0):
     * Creates Adam optimizer
     * MSE loss criterion
     * Moves model to device
     * spectral_weight: weight for spectral consistency loss (0.0 = disabled)
     * sfreq: sampling frequency for CSD computation (used when spectral_weight > 0)

   - _spectral_consistency_loss(x: Tensor, x_recon: Tensor) -> Tensor:
     * Computes CSD of x and CSD of x_recon using scipy.signal.csd (Welch)
     * Returns MSE between the two CSDs (real + imaginary parts)
     * Only called when spectral_weight > 0
     * Detaches from autograd for the CSD computation (scipy), uses the
       reconstruction MSE gradient path only. The spectral loss acts as an
       additional penalty on the reconstruction, not a differentiable path
       through CSD.
     * NOTE: A simpler approach -- compute power spectral density (PSD) per
       channel via torch.fft.rfft and compare. This IS differentiable.
       Use torch FFT, not scipy: psd_x = |fft(x)|^2, psd_recon = |fft(x_recon)|^2,
       loss = MSE(log(psd_x + eps), log(psd_recon + eps)). Log-scale because
       power spectra span orders of magnitude.

   - train(train_loader: DataLoader, *, n_epochs: int = 100,
     val_loader: DataLoader | None = None,
     patience: int = 10, log_every: int = 10) -> dict:
     * Standard training loop with MSE loss + spectral_weight * spectral_loss
     * If val_loader provided: compute val loss each epoch, track best val loss
     * Early stopping: if val loss does not improve for `patience` epochs, stop
     * Save checkpoint at best val loss (if checkpoint_dir set)
     * Returns dict with keys: train_losses (list[float] per epoch),
       val_losses (list[float] | None), best_epoch (int), final_epoch (int)

   - save_checkpoint(path: Path) -> None: saves model state_dict + optimizer state_dict + epoch
   - load_checkpoint(path: Path) -> int: loads checkpoint, returns epoch number
   - evaluate(data_loader: DataLoader) -> float: returns mean MSE on dataset

   Use `from __future__ import annotations`, NumPy docstrings, type hints.
   Import DataLoader from torch.utils.data. Use torch.save/torch.load for checkpoints.
