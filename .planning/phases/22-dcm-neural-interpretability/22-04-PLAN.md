  <files>src/pyro_dcm/neural_data_models/latent_extraction.py, src/pyro_dcm/neural_data_models/__init__.py, tests/test_neural_data_latent_extraction.py</files>
  <action>
1. Create `src/pyro_dcm/neural_data_models/latent_extraction.py`:

   a. `extract_latent_trajectories(model: MEGAutoencoder, data: Tensor | DataLoader, *,
      device: str = "cpu", batch_size: int = 64) -> np.ndarray`:
      - If data is a Tensor, wraps it in a DataLoader with batch_size
      - Sets model.eval(), uses torch.no_grad()
      - Iterates over batches, calls model.encode(batch.to(device))
      - Concatenates all latent outputs: shape (n_samples, T, N_latent)
      - Returns as numpy array (detached from graph)
      - NumPy docstring with shape annotations

   b. `compute_latent_csd(latent_trajectories: np.ndarray, *, sfreq: float = 250.0,
      fmin: float = 1.0, fmax: float = 45.0, n_freqs: int = 64,
      average_over_samples: bool = True) -> dict[str, np.ndarray]`:
      - latent_trajectories shape: (n_samples, T, N_latent) or (T, N_latent)
      - If 3D and average_over_samples=True: average CSD across samples
      - If 3D and average_over_samples=False: compute CSD per sample, return (n_samples, F, N, N)
      - If 2D: single trajectory, compute CSD directly
      - freqs = np.linspace(fmin, fmax, n_freqs)
      - For each sample, call compute_empirical_csd(sample, fs=sfreq, freqs=freqs)
      - Returns dict: {"csd": np.ndarray (F, N, N) or (n_samples, F, N, N),
        "freqs": np.ndarray (F,), "sfreq": float, "n_latent": int}
      - Import compute_empirical_csd from pyro_dcm.forward_models.csd_computation

   c. `prepare_for_spectral_dcm(csd_result: dict) -> dict[str, torch.Tensor]`:
      - Convenience function converting numpy CSD dict to torch tensors for spectral DCM
      - Returns {"csd": torch.tensor(complex128), "freqs": torch.tensor(float64),
        "a_mask": torch.ones(N, N, float64)}
      - Generates full connectivity mask by default (all connections possible)

2. Update __init__.py to export extract_latent_trajectories, compute_latent_csd,
   prepare_for_spectral_dcm.

3. Create tests/test_neural_data_latent_extraction.py:
   a. test_extract_latent_trajectories_shape: (10, 100, 6) input -> (10, 100, 4) latent
   b. test_extract_latent_trajectories_from_dataloader: Same but with DataLoader input
   c. test_extract_latent_trajectories_eval_mode: Model is in eval mode during extraction
   d. test_compute_latent_csd_2d_input: (T, N) -> (F, N, N)
   e. test_compute_latent_csd_3d_averaged: (n, T, N) with average=True -> (F, N, N)
   f. test_compute_latent_csd_3d_per_sample: (n, T, N) with average=False -> (n, F, N, N)
   g. test_compute_latent_csd_hermitian: CSD[f, i, j] == conj(CSD[f, j, i])
   h. test_prepare_for_spectral_dcm_dtypes: csd is complex128, freqs is float64, a_mask is float64

<task type="auto">
  <name>Task 2: Synthetic end-to-end integration test</name>
  <files>tests/test_meg_pipeline_synthetic.py</files>
  <action>
Create tests/test_meg_pipeline_synthetic.py -- a comprehensive integration test that
proves the FULL pipeline works on synthetic data. This is the primary risk reduction for
Phase 22: if this test passes, the pipeline is ready for real data.

Test structure:

1. `test_synthetic_meg_pipeline_end_to_end`:
   - Generate synthetic "ROI timeseries": 6 channels, 250 Hz, 2 seconds (500 samples),
     20 samples. Use coupled sinusoids with known cross-spectral structure:
     * ROI 0 = sin(2*pi*10*t) + noise (10 Hz oscillation)
     * ROI 1 = 0.5 * ROI_0_delayed + sin(2*pi*20*t) + noise (coupled to ROI 0)
     * ROIs 2-5 = independent sinusoids at different frequencies + noise
     This creates known cross-spectral structure for validation.

   - Train MEGAutoencoder: n_roi=6, n_latent=4, hidden_size=32, 30 epochs
     Verify: final loss < initial loss (training converges)

   - Extract latent trajectories: shape (20, 500, 4)

   - Compute latent CSD: freqs 1-45 Hz, 64 bins, averaged over samples
     Verify: shape (64, 4, 4), Hermitian, auto-spectra non-negative

   - Prepare for spectral DCM: convert to torch tensors
     Verify: dtypes correct

   - Fit spectral DCM with MEG-adapted parameters:
     * Use spectral_dcm_model with prior_a_var=1/16, eig_clamp=-1.0
     * Use create_guide with init_scale=0.01
     * Run run_svi for 200 steps (smoke test, not full convergence)
     * Verify: ELBO decreases (loss goes down), no NaN in posterior A

   This test should take < 2 minutes on laptop (synthetic data, short training,
   few SVI steps). Mark with @pytest.mark.slow if > 30 seconds.

2. `test_raw_vs_latent_csd_shapes`:
   - Compute CSD directly from the raw synthetic ROI timeseries (6-channel)
   - Compute CSD from latent trajectories (4-channel)
   - Verify: raw CSD is (64, 6, 6), latent CSD is (64, 4, 4)
   - Both are Hermitian with non-negative auto-spectra

Use `from __future__ import annotations`, NumPy docstrings, full imports (no wildcards).
  </action>
