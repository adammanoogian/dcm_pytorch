  <action>
1. Create `src/pyro_dcm/io/camcan_loader.py` with:

   Module-level constants:
   - CAMCAN_SFREQ = 250.0  # target sampling rate after resampling
   - CAMCAN_FMIN = 1.0  # bandpass lower bound
   - CAMCAN_FMAX = 45.0  # bandpass upper bound
   - CAMCAN_TMIN = -0.2  # epoch start relative to event
   - CAMCAN_TMAX = 0.8  # epoch end relative to event
   - DEFAULT_ROI_NAMES: list of task-relevant Desikan-Killiany ROI names:
     ["precentral-lh", "precentral-rh", "postcentral-lh", "postcentral-rh",
      "superiortemporal-lh", "superiortemporal-rh"]
     (motor cortex L/R, somatosensory L/R, auditory cortex L/R -- sensorimotor task)

   Functions:

   a. `load_camcan_meg(fif_path: str | Path, *, l_freq: float = CAMCAN_FMIN,
      h_freq: float = CAMCAN_FMAX, sfreq: float = CAMCAN_SFREQ) -> mne.io.Raw`:
      - Calls _require_mne() guard
      - mne.io.read_raw_fif(fif_path, preload=True)
      - raw.filter(l_freq, h_freq)
      - raw.resample(sfreq)
      - Returns preprocessed Raw

   b. `epoch_sensorimotor(raw: mne.io.Raw, *, stim_channel: str = "STI101",
      event_id: dict | None = None, tmin: float = CAMCAN_TMIN,
      tmax: float = CAMCAN_TMAX) -> mne.Epochs`:
      - events = mne.find_events(raw, stim_channel=stim_channel)
      - epochs = mne.Epochs(raw, events, event_id=event_id, tmin=tmin, tmax=tmax,
        preload=True, baseline=(None, 0))
      - Returns Epochs

   c. `source_reconstruct_epochs(epochs: mne.Epochs, *, subjects_dir: str | Path | None = None,
      subject: str = "fsaverage", spacing: str = "oct6",
      reg: float = 0.05, roi_names: list[str] | None = None) -> dict`:
      - Uses fsaverage template anatomy by default (no per-subject MRI needed)
      - src = mne.setup_source_space(subject, spacing=spacing, subjects_dir=subjects_dir)
      - fwd = mne.make_forward_solution(epochs.info, trans=subject, src=src, bem=...)
        NOTE: For fsaverage, trans can be "fsaverage" identity; BEM uses
        mne.read_bem_solution or make_bem_model
      - data_cov = mne.compute_covariance(epochs, tmin=0.0, tmax=None)
      - noise_cov = mne.compute_covariance(epochs, tmin=None, tmax=0.0)
      - filters = mne.beamformer.make_lcmv(epochs.info, fwd, data_cov,
          noise_cov=noise_cov, reg=reg, weight_norm="unit-noise-gain",
          pick_ori="max-power")
      - stcs = mne.beamformer.apply_lcmv_epochs(epochs, filters)
      - labels = mne.read_labels_from_annot(subject, "aparc", subjects_dir=subjects_dir)
      - If roi_names is None, use DEFAULT_ROI_NAMES
      - selected_labels = [l for l in labels if l.name in roi_names]
      - Validate that all roi_names were found; raise ValueError listing missing ones
      - roi_ts = mne.extract_label_time_course(stcs, selected_labels, src, mode="mean_flip")
      - Returns dict with keys: "timeseries" (n_epochs, T, N_roi) float tensor,
        "times" (T,) tensor, "roi_names" list[str], "sfreq" float, "n_epochs" int

   d. `load_and_preprocess_subject(fif_path: str | Path, *, roi_names: list[str] | None = None,
      subjects_dir: str | Path | None = None, **kwargs) -> dict`:
      - Convenience function chaining load_camcan_meg -> epoch_sensorimotor ->
        source_reconstruct_epochs
      - Returns the dict from source_reconstruct_epochs

   All functions use _require_mne() guard from mne_loader.py (import it).
   Use `from __future__ import annotations`, NumPy docstrings, type hints.
