<objective>
Create a synthetic MEG timeseries simulator that generates multivariate timeseries
from a known effective connectivity matrix A, suitable for training the LSTM autoencoder.

Purpose: The simulation-first approach requires generating timeseries (not just CSD) from
a known spectral DCM so we can: (1) train the autoencoder on timeseries with known
ground-truth connectivity, (2) verify that perturbations to A are recoverable through
the latent DCM pipeline. The existing spectral_simulator only produces CSD (frequency
domain). This plan adds time-domain simulation via Ornstein-Uhlenbeck SDE (the linear
stochastic process underlying spectral DCM).

The simulator also provides a `make_sensorimotor_A` helper that creates a 10-region
connectivity matrix mimicking a sensorimotor network: M1 L/R, S1 L/R, PMC L/R, SMA L/R,
A1 L/R -- with realistic connection patterns (strong M1-S1 coupling, bilateral
homotopic connections, auditory-to-motor feedforward).

Output: New `src/pyro_dcm/simulators/meg_simulator.py` with timeseries generation +
sensorimotor network factory, plus comprehensive tests.
</objective>

  <action>
1. Create `src/pyro_dcm/simulators/meg_simulator.py`:

   Module-level constants:
   - SENSORIMOTOR_ROI_NAMES: list[str] = [
       "M1_lh", "M1_rh", "S1_lh", "S1_rh",
       "PMC_lh", "PMC_rh", "SMA_lh", "SMA_rh",
       "A1_lh", "A1_rh"
     ]
     (10 regions: primary motor, somatosensory, premotor, SMA, auditory, bilateral)

   Functions:

   a. `simulate_meg_timeseries(A, *, sfreq=250.0, duration=4.0, n_samples=50,
      sigma=1.0, seed=None) -> dict`:
      - A: (N, N) float64 effective connectivity (must be stable)
      - Validates A stability (all eigenvalues have negative real parts)
      - Simulates n_samples independent realizations of the Ornstein-Uhlenbeck SDE:
        dx = A @ x dt + sigma * I dW
      - Uses Euler-Maruyama integration: dt = 1/sfreq
        x[t+1] = x[t] + A @ x[t] * dt + sigma * sqrt(dt) * noise
      - T = int(sfreq * duration) timepoints per sample
      - Returns dict:
        * "timeseries": torch.Tensor (n_samples, T, N) float64
        * "A": torch.Tensor (N, N) float64 -- ground truth
        * "sfreq": float
        * "duration": float
        * "roi_names": list[str] | None (set if using make_sensorimotor_A)
        * "sigma": float
      - NumPy docstring with full shape annotations and math reference.
        Cite: the OU process is the time-domain realization of the linear
        stochastic model underlying spectral DCM [REF-010].

   b. `make_sensorimotor_A(*, self_connection=-0.5, intra_strength=0.15,
      bilateral_strength=0.08, feedforward_strength=0.10,
      seed=None) -> torch.Tensor`:
      - Creates 10x10 A matrix with structured connectivity:
        * Diagonal: self_connection (negative, all regions)
        * M1 <-> S1 (ipsilateral): intra_strength (bidirectional)
        * PMC -> M1 (ipsilateral): feedforward_strength
        * SMA -> M1 (ipsilateral): feedforward_strength
        * SMA -> PMC (ipsilateral): feedforward_strength * 0.5
        * A1 -> M1 (ipsilateral): feedforward_strength * 0.5 (auditory-motor coupling)
        * Bilateral homotopic: bilateral_strength (e.g., M1_lh <-> M1_rh)
        * Small random noise on other connections (seed-controlled, scale 0.02)
      - Validates stability; rescales if needed (via make_stable_A_spectral pattern)
      - Returns (10, 10) float64 tensor
      - NumPy docstring describing the sensorimotor network structure

   c. `generate_meg_dataset(A=None, *, n_roi=10, sfreq=250.0, duration=4.0,
      n_train=200, n_val=50, sigma=1.0, seed=42) -> dict`:
      - Convenience function for generating train/val datasets
      - If A is None: uses make_sensorimotor_A(seed=seed) for 10 regions,
        or make_stable_A_spectral(n_roi, seed=seed) for other sizes
      - Calls simulate_meg_timeseries twice (with different seed offsets)
      - Returns dict:
        * "train": torch.Tensor (n_train, T, N)
        * "val": torch.Tensor (n_val, T, N)
        * "A": ground-truth A
        * "roi_names": list[str] or None
        * "sfreq": float
        * "metadata": dict with all generation params
