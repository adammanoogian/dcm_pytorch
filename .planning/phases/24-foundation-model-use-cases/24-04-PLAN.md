  <action>
1. **scripts/24_compare_crossmodal.py**: Cross-modal A-matrix comparison pipeline.

   Define utility functions at module scope (reusable from tests):

   - `def normalize_a_matrix(a_matrix: np.ndarray) -> np.ndarray`:
     Normalizes A matrix by dividing by its Frobenius norm. This makes cross-modal
     comparison scale-independent (Pitfall 4 from RESEARCH.md -- fMRI at 1 Hz vs
     M/EEG at 200 Hz produces different magnitude A matrices).

   - `def compute_pearson_correlation(a1: np.ndarray, a2: np.ndarray) -> float`:
     Flattens both normalized A matrices and computes Pearson r. Returns correlation
     coefficient. Uses `scipy.stats.pearsonr`.

   - `def compute_sign_kappa(a1: np.ndarray, a2: np.ndarray, threshold: float = 0.0) -> float`:
     Binarizes A matrices into {-1, 0, +1} based on sign (with optional threshold for
     near-zero elements). Computes Cohen's kappa on the sign patterns using
     `sklearn.metrics.cohen_kappa_score`. Returns kappa.

   - `def compute_credible_interval_overlap(a1_mean: np.ndarray, a1_std: np.ndarray, a2_mean: np.ndarray, a2_std: np.ndarray, z: float = 1.96) -> float`:
     For each (i, j) element, checks if 95% CIs overlap between modalities. Returns
     fraction of elements with overlapping CIs.

   - `def plot_comparison(a_fmri: np.ndarray, a_meeg: np.ndarray, roi_names: list[str], output_path: str) -> None`:
     Creates a 3-panel matplotlib figure:
     (a) fMRI A matrix heatmap with roi labels.
     (b) M/EEG A matrix heatmap with roi labels.
     (c) Scatter plot of fMRI vs M/EEG A elements with Pearson r annotation.
     Saves to output_path as PNG (300 dpi) and PDF.

   Main script (argparse):
   - `--fmri-results` (path to tribe_dcm_results.npz).
   - `--meeg-results` (path to meeg_dcm_results.npz).
   - `--output-dir` (default `results/phase24_comparison/`).
   - `--roi-mapping` (optional JSON mapping fMRI ROI names to M/EEG ROI names for
     alignment; if not provided, assumes same ROI ordering).
   - Load both .npz files.
   - Extract A_mean and A_std from each.
   - If roi-mapping provided, reorder one set of ROIs to match.
   - Compute all metrics: pearson_r, sign_kappa, ci_overlap_fraction.
   - Print formatted summary table.
   - Call plot_comparison.
   - Save metrics to `{output_dir}/crossmodal_metrics.json`.
   - Guard with `if __name__ == "__main__"`.

   parcellate_vertices_to_rois. Update __all__ list.

  <action>
Create unit tests for the comparison functions defined in 24_compare_crossmodal.py:

1. `test_normalize_a_matrix_unit_norm()`: Create random 4x4 matrix. Normalize it.
   Assert Frobenius norm of result is 1.0 (within atol=1e-10).

2. `test_pearson_identical_matrices()`: Create random A matrix. Compute Pearson r
   between it and itself. Assert r == 1.0 (within atol=1e-10).

3. `test_pearson_uncorrelated_matrices()`: Create two random A matrices with known
   orthogonal structure (e.g., A1 = upper triangular, A2 = lower triangular with
   different values). Assert |r| is small (< 0.5).

4. `test_sign_kappa_perfect_agreement()`: Create two A matrices with identical sign
   patterns but different magnitudes. Assert kappa == 1.0.

5. `test_sign_kappa_random_disagreement()`: Create two A matrices with opposite sign
   patterns. Assert kappa < 0.

6. `test_ci_overlap_identical()`: A1_mean = A2_mean, A1_std = A2_std = 0.1. Assert
   overlap fraction == 1.0.

7. `test_ci_overlap_separated()`: A1_mean = 0, A2_mean = 10, stds = 0.1. Assert
   overlap fraction == 0.0.

8. `test_normalize_preserves_sign_pattern()`: Verify normalization does not change
   the sign of any element (important for sign_kappa downstream).

Import comparison functions via:
