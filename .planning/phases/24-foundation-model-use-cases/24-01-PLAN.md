  <action>
Create `src/pyro_dcm/foundation/` package with three files:

1. **base_extractor.py**: Define `BaseExtractor(ABC)` with:
   - `__init__(self, model_name: str, device: torch.device | None = None)` -- stores
     model name and resolves device (CPU/CUDA).
   - Abstract method `load_model(self, checkpoint_path: str | None = None) -> None` --
     loads pretrained weights.
   - Abstract method `extract_latents(self, input_data: torch.Tensor, layer_names: list[str] | None = None) -> dict[str, torch.Tensor]` --
     returns dict mapping layer names to activation tensors.
   - Concrete method `extract_layer_activations(self, model: nn.Module, input_tensor: torch.Tensor, layer_names: list[str]) -> dict[str, torch.Tensor]` --
     implements the PyTorch forward-hook pattern from 24-RESEARCH.md Pattern 2.
     Registers hooks on named modules, runs forward pass with `torch.no_grad()`, removes
     hooks, returns activations dict. This is the shared hook utility.
   - All methods have NumPy-style docstrings with Parameters/Returns sections.
   - `from __future__ import annotations` at top.

2. **parcellation.py**: Implement `parcellate_vertices_to_rois`:
   - `def parcellate_vertices_to_rois(vertex_timeseries: np.ndarray, n_rois: int = 100, atlas_name: str = "schaefer") -> tuple[np.ndarray, list[str]]`
   - Takes vertex_timeseries shape (T, 20484) on fsaverage5 (10242 per hemisphere).
   - Uses `nilearn.datasets.fetch_atlas_schaefer_2018(n_rois=n_rois, resolution_mm=2)`
     to get atlas labels.
   - Splits vertex data into left hemi ([:, :10242]) and right hemi ([:, 10242:]).
   - For each ROI label, averages vertices belonging to that ROI.
   - Returns `(roi_timeseries, roi_names)` where roi_timeseries is shape (T, n_rois).
   - Uses `nilearn.surface.load_surf_data` for label loading, guarded with
     try/except ImportError for nilearn.
   - Add helper `def _fetch_schaefer_labels(n_rois: int) -> np.ndarray` that caches
     the atlas labels array to avoid repeated downloads.
   - NumPy-style docstrings, `from __future__ import annotations`.

3. **__init__.py**: Re-export `BaseExtractor` from base_extractor and
   `parcellate_vertices_to_rois` from parcellation. Add module docstring describing
   the foundation model extractor subpackage.

Follow existing project conventions: ruff-compatible, 88-char lines, type hints with
Python 3.10+ syntax.
