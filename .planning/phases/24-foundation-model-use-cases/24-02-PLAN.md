1. **tribe_extractor.py**: Create `TRIBEExtractor(BaseExtractor)`:

   - `__init__(self, cache_folder: str = "./tribe_cache", n_rois: int = 100, device: torch.device | None = None)`:
     Calls `super().__init__(model_name="tribe_v2", device=device)`. Stores cache_folder
     and n_rois. Sets `self.model_: TribeModel | None = None` (fitted attribute convention).

   - `load_model(self, checkpoint_path: str | None = None) -> None`:
     Imports `tribev2.demo_utils.TribeModel` (guarded with try/except ImportError,
     message: "Install tribev2: pip install 'tribev2 @ git+https://github.com/facebookresearch/tribev2.git'").
     Calls `TribeModel.from_pretrained("facebook/tribev2", cache_folder=self.cache_folder)`.
     Stores in `self.model_`.

   - `predict_vertex_timeseries(self, video_path: str | None = None, audio_path: str | None = None, events_df: Any = None) -> np.ndarray`:
     If events_df is None, generates from video_path via `self.model_.get_events_dataframe()`.
     Calls `self.model_.predict(events=events_df)`. Returns np.ndarray shape (T, 20484).
     Raises ValueError if model_ is None (not loaded).

   - `extract_roi_timeseries(self, vertex_timeseries: np.ndarray) -> tuple[np.ndarray, list[str]]`:
     Calls `parcellate_vertices_to_rois(vertex_timeseries, n_rois=self.n_rois)`.
     Returns (roi_timeseries, roi_names).

   - `extract_latents(self, input_data: torch.Tensor, layer_names: list[str] | None = None) -> dict[str, torch.Tensor]`:
     Implements abstract method. If layer_names is None, returns
     `{"roi_timeseries": torch.from_numpy(roi_ts)}` from predict+parcellate.
     If layer_names provided, uses `self.extract_layer_activations()` to hook
     internal transformer layers for deeper latent extraction.

   - NumPy-style docstrings on all methods. Import guard for tribev2.
   - `from __future__ import annotations` at top.

   All tests use `unittest.mock.patch` for tribev2 imports. No `@pytest.mark.foundation`

1. **scripts/24_extract_tribe_latents.py**: Pipeline script for TRIBE v2 extraction.

   Structure follows existing pipeline script convention ({stage}_{verb}_{noun}.py):
   - argparse with: `--video-path` (stimulus video), `--output-dir` (results dir,
     default `results/phase24_tribe/`), `--n-rois` (default 100), `--cache-folder`
     (TRIBE v2 cache, default `./tribe_cache`).
   - Instantiate `TRIBEExtractor(n_rois=args.n_rois, cache_folder=args.cache_folder)`.
   - Call `load_model()`.
   - Call `predict_vertex_timeseries(video_path=args.video_path)`.
   - Call `extract_roi_timeseries(vertex_timeseries)`.
   - Save to `{output_dir}/tribe_roi_timeseries.npz` with keys: `roi_timeseries`,
     `roi_names`, `n_rois`, `vertex_shape`, `stimulus_path`.
   - Print summary: shape, number of ROIs, timepoints, output path.
   - Guard with `if __name__ == "__main__"`.

2. **scripts/24_fit_dcm_tribe.py**: Pipeline script for spectral DCM on TRIBE output.

   Structure:
   - argparse with: `--input-npz` (from extraction script), `--output-dir`
     (default `results/phase24_tribe/`), `--n-regions` (how many ROIs to fit DCM on,
     default 6 -- select task-relevant subset), `--roi-indices` (comma-separated ROI
     indices to select), `--num-steps` (SVI steps, default 2000), `--n-restarts`
     (multi-start, default 10), `--lr` (learning rate, default 0.01).
   - Load roi_timeseries from npz.
   - Select subset of ROIs based on --roi-indices (or first N).
   - Compute empirical CSD from ROI timeseries using
     `pyro_dcm.forward_models.csd_computation.compute_empirical_csd` (existing function).
   - Set up spectral_dcm_model with full A mask (N x N ones).
   - Create guide via `create_guide("AutoLowRankMVN", ...)`.
   - Run SVI via `run_svi(model, guide, model_args, num_steps, lr, n_restarts=n_restarts, guide_factory=...)`.
   - Extract posterior A via `extract_posterior_params`.
   - Save results to `{output_dir}/tribe_dcm_results.npz`: A_mean, A_std,
     final_loss, roi_names_selected.
   - Print posterior A matrix and summary.

   Follow the pattern from `scripts/demo_spectral_dcm.py` for the SVI fitting logic.

3. **cluster/sbatch/24_tribe_extract.slurm**: M3 cluster sbatch script.

   - `#SBATCH --job-name=tribe_extract`
   - `#SBATCH --partition=gpu` (or equivalent M3 GPU partition)
   - `#SBATCH --gres=gpu:A100:1` (40 GB minimum for TRIBE v2)
   - `#SBATCH --mem=64G` (TRIBE v2 + LLaMA needs headroom)
   - `#SBATCH --time=02:00:00`
   - `#SBATCH --output=cluster/logs/tribe_extract_%j.out`
   - `#SBATCH --error=cluster/logs/tribe_extract_%j.err`
   - Module loads for CUDA/Python.
   - `pip install 'numpy>=1.26.4,<2.1.0'` (Pitfall 2 from RESEARCH.md).
   - `pip install 'tribev2[plotting] @ git+https://github.com/facebookresearch/tribev2.git'`.
   - Set `HF_HUB_DOWNLOAD_TIMEOUT=300` (Pitfall 1).
   - Run `python scripts/24_extract_tribe_latents.py --video-path $STIMULUS_PATH --output-dir results/phase24_tribe/`.
   - Then run `python scripts/24_fit_dcm_tribe.py --input-npz results/phase24_tribe/tribe_roi_timeseries.npz --output-dir results/phase24_tribe/`.
