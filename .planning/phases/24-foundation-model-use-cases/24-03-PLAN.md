1. **labram_extractor.py**: Create `LaBraMExtractor(BaseExtractor)`:

   - `__init__(self, n_times: int = 1600, n_chans: int = 64, n_outputs: int = 4, sfreq: float = 200.0, patch_size: int = 200, embed_dim: int = 200, n_layers: int = 12, n_heads: int = 10, device: torch.device | None = None)`:
     Stores all LaBraM hyperparameters. Calls `super().__init__("labram", device)`.
     Sets `self.model_: nn.Module | None = None`.

   - `load_model(self, checkpoint_path: str | None = None) -> None`:
     Imports `braindecode.models.Labram` (guarded: try/except ImportError with install
     hint "pip install braindecode>=1.3.0"). If checkpoint_path is None, uses
     `Labram.from_pretrained("braindecode/labram-pretrained")`. Otherwise creates
     `Labram(...)` with stored hyperparams and loads weights from checkpoint_path.
     Moves to self.device, sets eval mode. Stores in `self.model_`.

   - `extract_features(self, eeg_input: torch.Tensor) -> dict[str, torch.Tensor]`:
     Calls `self.model_(eeg_input, return_features=True)`. Returns dict with keys
     `"features"` shape (batch, n_patches, embed_dim) and `"cls_token"` shape
     (batch, embed_dim). This is LaBraM's built-in feature extraction.
     Raises ValueError if model_ is None.

   - `extract_latents(self, input_data: torch.Tensor, layer_names: list[str] | None = None) -> dict[str, torch.Tensor]`:
     If layer_names is None, returns `extract_features(input_data)`.
     If layer_names provided, uses `self.extract_layer_activations()` inherited from
     BaseExtractor to hook specific transformer blocks.

   - `reduce_to_dcm_space(self, features: torch.Tensor, n_components: int = 4) -> tuple[np.ndarray, Any]`:
     Takes features shape (batch, n_patches, embed_dim), reshapes to (batch * n_patches,
     embed_dim), applies PCA to reduce to n_components dimensions, reshapes back to
     (batch, n_patches, n_components). Returns (reduced, pca_model). Uses
     `sklearn.decomposition.PCA`. Import guarded.

   Pitfall 5 addressed: docstring notes that channel ordering matters. Method signature
   accepts `chs_info` parameter for future use. NumPy-style docstrings throughout.

2. **brainomni_extractor.py**: Create `BrainOmniExtractor(BaseExtractor)`:

   - `__init__(self, modality: str = "eeg", device: torch.device | None = None)`:
     Stores modality ("eeg" or "meg"). Calls `super().__init__("brainomni", device)`.

   - `load_model(self, checkpoint_path: str | None = None) -> None`:
     Documents that BrainOmni requires cloning the repo and downloading HuggingFace
     checkpoints. Try importing from BrainOmni package (guarded with ImportError and
     install hint referencing https://github.com/OpenTSLab/BrainOmni). If
     checkpoint_path provided, loads from file. Otherwise tries HuggingFace download
     via `huggingface_hub.hf_hub_download`. Sets eval mode.

   - `extract_latents(self, input_data: torch.Tensor, layer_names: list[str] | None = None) -> dict[str, torch.Tensor]`:
     Uses `self.extract_layer_activations()` from BaseExtractor to hook transformer
     layers. If layer_names is None, hooks all encoder blocks. Returns activations dict.

   - `reduce_to_dcm_space(self, activations: dict[str, torch.Tensor], layer_name: str, n_components: int = 4) -> tuple[np.ndarray, Any]`:
     Selects activation from specified layer, applies PCA reduction same as LaBraM.

   Note: BrainOmni API is less mature than LaBraM (Pitfall noted in RESEARCH.md).
   The extractor is designed defensively with clear error messages for missing deps.

1. **scripts/24_extract_meeg_latents.py**: Pipeline script for M/EEG latent extraction.

   - argparse with: `--model` (choice: "labram", "brainomni", default "labram"),
     `--input-fif` (MNE .fif file with epoched M/EEG data), `--output-dir`
     (default `results/phase24_meeg/`), `--n-components` (PCA dims for DCM, default 4),
     `--checkpoint` (optional pretrained weights path), `--sfreq` (sample rate, default 200),
     `--n-chans` (channels, default 64).
   - If model == "labram":
     - Load input data from .fif using `mne.read_epochs()` into numpy array (batch, n_chans, n_times).
     - Instantiate `LaBraMExtractor(n_times=..., n_chans=..., sfreq=args.sfreq)`.
     - Call `load_model(checkpoint_path=args.checkpoint)`.
     - Call `extract_features(input_tensor)`.
     - Call `reduce_to_dcm_space(features["features"], n_components=args.n_components)`.
   - If model == "brainomni":
     - Similar flow with BrainOmniExtractor.
   - Save to `{output_dir}/meeg_latent_dynamics.npz` with keys: `latent_dynamics`
     shape (n_epochs, n_patches, n_components), `model_name`, `n_components`,
     `pca_explained_variance`.
   - Print summary: model, input shape, latent shape, variance explained.
   - Guard with `if __name__ == "__main__"`.

2. **scripts/24_fit_dcm_meeg.py**: Pipeline script for DCM on M/EEG latents.

   - argparse with: `--input-npz` (from extraction script), `--output-dir`
     (default `results/phase24_meeg/`), `--dcm-type` (choice: "spectral", "latent_circuit",
     default "spectral"), `--num-steps` (SVI steps, default 2000), `--n-restarts`
     (multi-start, default 10), `--lr` (default 0.01).
   - Load latent_dynamics from npz.
   - If dcm_type == "spectral":
     - Compute CSD from latent dynamics using `compute_empirical_csd` -- treats each
       epoch's latent trajectory as a timeseries, computes Welch CSD.
     - Fit spectral_dcm_model with full A mask.
     - Use `create_guide("AutoLowRankMVN", ...)` and `run_svi(...)`.
   - If dcm_type == "latent_circuit":
     - Concatenate epochs into a single trajectory or pick representative epoch.
     - Create stimulus tensor (ones for driving input).
     - Fit latent_circuit_dcm_model.
     - Use multi-start SVI.
   - Extract posterior via `extract_posterior_params`.
   - Save to `{output_dir}/meeg_dcm_results.npz`: A_mean, A_std, final_loss,
     dcm_type, model_name.
   - Print posterior A matrix summary.

3. **cluster/sbatch/24_meeg_extract.slurm**: M3 cluster sbatch for M/EEG extraction.

   - `#SBATCH --job-name=meeg_extract`
   - `#SBATCH --partition=gpu` (LaBraM/BrainOmni smaller than TRIBE)
   - `#SBATCH --gres=gpu:1` (any GPU with 16GB+ sufficient for LaBraM)
   - `#SBATCH --mem=32G`
   - `#SBATCH --time=01:00:00`
   - `#SBATCH --output=cluster/logs/meeg_extract_%j.out`
   - `#SBATCH --error=cluster/logs/meeg_extract_%j.err`
   - Module loads for CUDA/Python.
   - `pip install braindecode>=1.3.0 huggingface_hub>=0.20`.
   - Run extraction: `python scripts/24_extract_meeg_latents.py --model labram --input-fif $INPUT_FIF --output-dir results/phase24_meeg/`.
   - Run DCM fit: `python scripts/24_fit_dcm_meeg.py --input-npz results/phase24_meeg/meeg_latent_dynamics.npz --output-dir results/phase24_meeg/`.
