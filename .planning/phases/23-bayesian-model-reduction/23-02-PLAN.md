Add two functions to `src/pyro_dcm/model_selection/bmr.py`:

1. **enumerate_reduced_models**:
   ```python
   def enumerate_reduced_models(
       prior_mean: torch.Tensor,
       prior_cov: torch.Tensor,
       prunable_indices: list[int],
       shrinkage_variance: float = 1e-8,
   ) -> list[dict[str, Any]]:
   ```

   Generates all 2^k - 1 non-trivial subsets of `prunable_indices` (excluding the empty set, which is the full model). For each subset, creates reduced priors using `make_reduced_prior_zero_connection` (from Plan 01).

   Returns a list of dicts, each with:
   - `"pruned_indices"`: tuple of indices pruned in this reduction
   - `"reduced_prior_mean"`: tensor
   - `"reduced_prior_cov"`: tensor
   - `"n_pruned"`: number of connections removed
   - `"label"`: human-readable label like "prune [2, 5]"

   IMPORTANT: For large k (>15), warn that enumeration is exponential (2^k models). If k > 20, raise ValueError -- use greedy search instead (document this in docstring but do NOT implement greedy in this plan; that's future work).

   Use `itertools.combinations` to enumerate subsets of each size 1..k systematically, rather than `itertools.product` or bit-masking, to produce results grouped by pruning level (prune-1, prune-2, ..., prune-k).

2. **bmr_circuit_selection**:
   ```python
   def bmr_circuit_selection(
       posterior_mean: torch.Tensor,
       posterior_cov: torch.Tensor,
       prior_mean: torch.Tensor,
       prior_cov: torch.Tensor,
       prunable_indices: list[int],
       shrinkage_variance: float = 1e-8,
   ) -> dict[str, Any]:
   ```

   The main circuit-selection entry point. Steps:
   1. Call `enumerate_reduced_models` to get all candidate reductions.
   2. For each candidate, call `bayesian_model_reduction` to compute delta_log_evidence.
   3. Collect results and sort by delta_log_evidence (descending -- highest = best).
   4. Include the full model as baseline (delta_log_evidence = 0, pruned_indices = ()).

   Returns a dict with:
   - `"results"`: list of dicts sorted by delta_log_evidence descending, each with:
     - `"pruned_indices"`: tuple
     - `"delta_log_evidence"`: float
     - `"n_pruned"`: int
     - `"label"`: str
     - `"reduced_posterior_mean"`: tensor (from BMR)
     - `"reduced_posterior_cov"`: tensor (from BMR)
   - `"best"`: the result dict with highest delta_log_evidence
   - `"full_model_rank"`: 1-indexed rank of the full model (0 pruned) in the sorted list
   - `"n_candidates"`: total number of models evaluated (2^k)
   - `"prunable_indices"`: copy of input

   NumPy-style docstring citing [REF-070].

3. Update `src/pyro_dcm/model_selection/__init__.py` to re-export:
   - `enumerate_reduced_models`
   - `bmr_circuit_selection`
   - `make_reduced_prior_zero_connection`
