Implement the core Bayesian Model Reduction function that computes the analytic change in log model evidence when switching from full-model priors to reduced-model priors, per Friston & Penny (2011).

Purpose: BMR enables scoring thousands of reduced DCM architectures from a single full-model SVI fit, avoiding expensive per-architecture refitting. This is the mathematical foundation for circuit-size selection in Phase 23.

3. Create `src/pyro_dcm/model_selection/bmr.py`:
   - Module docstring citing [REF-070] Friston & Penny (2011)
   - `from __future__ import annotations`
   - Import torch

   Function signature:
   ```python
   def bayesian_model_reduction(
       posterior_mean: torch.Tensor,
       posterior_cov: torch.Tensor,
       prior_mean: torch.Tensor,
       prior_cov: torch.Tensor,
       reduced_prior_mean: torch.Tensor,
       reduced_prior_cov: torch.Tensor,
   ) -> tuple[float, torch.Tensor, torch.Tensor]:
   ```

   The function implements [REF-070] Eq. 4-8. The math:

   The BMR computes the posterior and free energy that would obtain under
   reduced priors, using the full-model posterior as a sufficient statistic.

   Step 1: Compute the reduced posterior via Bayes' rule update.
   The full-model posterior q_f(theta) = N(mu_f, Sigma_f) was obtained under
   full prior p_f(theta) = N(mu_0, Sigma_0). Under a reduced prior
   p_r(theta) = N(mu_r0, Sigma_r0), the reduced posterior is:

   Sigma_r_post^{-1} = Sigma_f^{-1} + Sigma_r0^{-1} - Sigma_0^{-1}
   mu_r_post = Sigma_r_post @ (Sigma_f^{-1} @ mu_f + Sigma_r0^{-1} @ mu_r0 - Sigma_0^{-1} @ mu_0)

   Step 2: Compute the change in free energy (log evidence difference).
   delta_F = F_reduced - F_full, where:
   delta_F = 1/2 * [log|Sigma_r_post| - log|Sigma_f|
                   + log|Sigma_0| - log|Sigma_r0|
                   + mu_r_post^T Sigma_r_post^{-1} mu_r_post
                   - mu_f^T Sigma_f^{-1} mu_f
                   + mu_r0^T Sigma_r0^{-1} mu_r0
                   - mu_0^T Sigma_0^{-1} mu_0]

   (This is the difference of two log-normalizing constants of the posterior
   Gaussians plus the prior normalization terms.)

   Alternative simpler formulation (SPM12 spm_log_evidence.m):
   delta_F = 1/2 * [log|Sigma_r_post| - log|Sigma_f|
                   + log|P_r0| - log|P_0|
                   + (mu_f - mu_r0)^T P_r0 (mu_f - mu_r0)
                   - (mu_f - mu_0)^T P_0 (mu_f - mu_0)
                   + tr(P_r0 @ Sigma_f) - tr(P_0 @ Sigma_f)
                   - k_r + k_0]
   where P = Sigma^{-1} (precision), k = dimensionality.

   But the cleanest implementation follows SPM12's `spm_log_evidence`:
   ```
   delta_F = 1/2 * (
       slogdet(reduced_prior_prec @ Sigma_f)[1]         # log|P_r0 Sigma_f|
     - slogdet(prior_prec @ Sigma_f)[1]                 # - log|P_0 Sigma_f|  [note: these cancel the Sigma_f]
     + (mu_f - reduced_prior_mean) @ reduced_prior_prec @ (mu_f - reduced_prior_mean)
     - (mu_f - prior_mean) @ prior_prec @ (mu_f - prior_mean)
     + tr(reduced_prior_prec @ Sigma_f)
     - tr(prior_prec @ Sigma_f)
   ) * (-1)  ... actually
   ```

   USE THE CLEANEST FORMULATION. The key identity is:

   log p(y|m_r) - log p(y|m_f) = 1/2 * [
       log|Sigma_r_post| - log|Sigma_f|
       + log|prior_prec| - log|reduced_prior_prec|
       + (mu_f - reduced_prior_mean)^T reduced_prior_prec (mu_f - reduced_prior_mean)
       - (mu_f - prior_mean)^T prior_prec (mu_f - prior_mean)
       + tr((reduced_prior_prec - prior_prec) @ Sigma_f)
   ]

   Where Sigma_r_post is the reduced posterior covariance from Step 1.

   IMPLEMENTATION NOTES:
   - Use `torch.linalg.solve` for precision @ vector products, not `torch.inverse`.
   - Use `torch.linalg.slogdet` for log-determinants (numerically stable).
   - All tensors must be float64 for numerical accuracy.
   - If `Sigma_r_post` is not positive definite (reduced prior is incompatible with data), return delta_F = -inf and warn.
   - Validate inputs: all tensors same shape, covariances symmetric, positive definite check via Cholesky.

   Returns:
   - `delta_log_evidence` (float): Change in log model evidence (positive = reduced model preferred).
   - `reduced_posterior_mean` (Tensor): Posterior mean under reduced priors.
   - `reduced_posterior_cov` (Tensor): Posterior covariance under reduced priors.

   NumPy-style docstring citing [REF-070] Eq. 4-8.

Create `tests/test_bmr.py` with the following test cases:

1. **test_identical_priors_zero_delta**: When `reduced_prior == prior` (no change), `delta_log_evidence == 0.0` (within atol=1e-6). This is the trivial identity check.

2. **test_analytic_1d_case**: 1D Gaussian case where BMR has a known closed-form answer.
   - Prior: N(0, 1). Posterior: N(0.5, 0.1). Reduced prior: N(0, 0.01).
   - The reduced posterior and delta_F can be computed by hand.
   - Assert delta_log_evidence matches the hand-computed value (atol=1e-4).

3. **test_tight_reduction_on_correct_zero**: When the posterior mean for a parameter is near zero (data agrees the connection is absent), tightening the prior around zero should INCREASE log evidence (positive delta_F). Create a 3D case where parameter 0 has posterior mean ~0.0 and std ~0.1, then reduce its prior to N(0, 1e-8). Assert delta_log_evidence > 0.

4. **test_tight_reduction_on_nonzero**: When the posterior mean is far from zero (data says connection exists), tightening the prior around zero should DECREASE log evidence (negative delta_F). Create a 3D case where parameter 0 has posterior mean ~2.0 and std ~0.1, then reduce its prior to N(0, 1e-8). Assert delta_log_evidence < 0.

5. **test_reduced_posterior_shape**: Verify returned `reduced_posterior_mean` and `reduced_posterior_cov` have correct shapes matching input dimensionality.

6. **test_make_reduced_prior_zero_connection**: Test the convenience function.
   - Create a 5D prior with mean=zeros and diagonal cov.
   - Reduce indices [1, 3].
   - Assert: reduced_prior_mean is zeros (unchanged); reduced_prior_cov diagonal at [1,1] and [3,3] equals shrinkage_variance; off-diagonal entries at [1,3] and [3,1] are zero; other diagonal entries unchanged.

7. **test_multidimensional_consistency**: Create a 4D case, compute BMR for reducing parameter 2, then independently compute BMR for the 1D marginal of parameter 2 (marginalize everything else out). Both should give the same delta_log_evidence (within atol=1e-4). This validates that the multivariate implementation is consistent with the marginal.

8. **test_symmetry_of_delta_f**: delta_F(full->reduced) should equal -delta_F(reduced->full). Swap the roles of prior and reduced_prior, assert the sign flips.

All tests use `torch.float64` tensors. Use `pytest.approx` or `torch.testing.assert_close` with appropriate tolerances.
