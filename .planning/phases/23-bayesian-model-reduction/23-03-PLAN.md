  <action>
Create `tests/test_bmr_vs_elbo.py`. This test validates BMR-03: BMR ranking agrees with brute-force ELBO comparison on synthetic data.

**Test design** (single test function, marked as `@pytest.mark.slow` since it runs multiple SVI fits):

`test_bmr_agrees_with_elbo_ranking`:

1. **Generate synthetic data** using `simulate_latent_circuit` with a small N=3 system:
   - A: 3x3 stable matrix with known connectivity (e.g., 0->1, 1->2 connections present; 2->0 absent).
   - C: 3x1 driving input to region 0.
   - No B matrices (linear only -- keeps test faster).
   - Duration: 5 seconds, dt=0.01.
   - Add observation noise (noise_prec=100, i.e., low noise).

2. **Fit the FULL model** (all A connections free) using SVI:
   - Use `latent_circuit_dcm_model` with a_mask = ones(3,3).
   - `create_guide(model, guide_type="auto_normal")`.
   - `run_svi(model, guide, model_args, num_steps=500)`.
   - Extract posterior via `extract_posterior_params`.

3. **Construct posterior mean and covariance for BMR**:
   - From the guide's posterior samples, build `posterior_mean` (vector of A_free elements) and `posterior_cov` (covariance matrix from samples).
   - The prior mean is zeros (matching the model's Normal(0, LC_A_PRIOR_VARIANCE) prior).
   - The prior covariance is `LC_A_PRIOR_VARIANCE * I`.
   - NOTE: `extract_posterior_params` returns per-site mean/std/samples. The A_free samples are shape `(num_samples, N*(N-1))` (off-diagonal only, since parameterize_A adds the diagonal). You need to flatten the relevant sample sites into a single parameter vector and compute the sample covariance matrix.

4. **Define candidate reduced models**: Create 3-4 reduced architectures:
   - Model A: prune the truly-absent connection (2->0). This should be BEST.
   - Model B: prune a truly-present connection (0->1). This should be WORSE.
   - Model C: prune both absent AND present connections. Mixed.
   - Full model (no pruning) as baseline.

5. **BMR scoring**: For each reduced model, call `bayesian_model_reduction` with reduced priors (zero-mean, 1e-8 variance on pruned connections).

6. **Brute-force ELBO**: For each reduced model, fit a separate SVI run with the corresponding `a_mask` (zeroing out the pruned connection's mask entry) and record the final ELBO loss.

7. **Compare rankings**:
   - Assert: BMR ranks the truly-absent-connection reduction as best (or tied for best).
   - Assert: BMR and ELBO agree on which of the candidate models is best (same top-1).
   - The ranking correlation (Spearman) between BMR delta_log_evidence and negative ELBO loss across the candidates should be positive (>0). Do NOT require perfect correlation -- SVI is noisy and BMR is an approximation. Just verify the top pick agrees and the correlation is positive.

8. **Wall time**: Record wall time for BMR (all candidates) vs brute-force (all separate SVI fits). Print comparison. BMR should be >10x faster.

**Practical notes:**
- Use small num_steps (500) and small num_samples (200) to keep test fast (~2-3 min total on laptop).
- Use `torch.manual_seed(42)` and `pyro.set_rng_seed(42)` for reproducibility.
- Mark with `@pytest.mark.slow` so it can be skipped in fast test runs.
- Import `simulate_latent_circuit` from `pyro_dcm.simulators.latent_circuit_simulator`.
- Import `make_stable_latent_circuit_A` from `pyro_dcm.simulators.latent_circuit_simulator`.

**The key assertion for BMR-03**: BMR top-1 model matches ELBO top-1 model. If the test is too noisy at 500 steps, increase to 1000 steps but keep the test under 5 minutes on laptop (3-4 SVI fits x 1000 steps at N=3 should be ~1-2 min each, totaling ~5-8 min). If projected >5 min, mark as `@pytest.mark.slow` AND add a note that full validation should run on cluster.

**IMPORTANT**: To construct the posterior covariance matrix from guide samples for BMR, you need to:
   - Draw samples from the guide (e.g., via Predictive).
   - Flatten A_free samples into a 1D parameter vector per sample.
   - Compute `torch.cov(samples.T)` to get the empirical covariance.
   - This is an approximation (the guide's true covariance may differ from the sample covariance), but with 1000+ samples it should be accurate enough.

   Alternatively, for AutoNormal guides, you can read the guide's `loc` and `scale` parameters directly from the param store (since AutoNormal is mean-field, the covariance is diagonal). This is more precise. Use `guide.loc` and `guide.scale` after SVI, then construct `posterior_cov = torch.diag(guide_scale ** 2)`. Prefer this approach as it avoids sampling noise in the covariance.
