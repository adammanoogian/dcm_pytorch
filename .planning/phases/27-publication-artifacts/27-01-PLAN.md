**New sections to add (number them as continuations of existing structure):**

**Section 1.6: Bilinear Extension (in methods.md Section 1; new subsection
in methods.tex under Generative Model)**

Extend the linear neural state equation (Section 1.1) to the full bilinear
form ([REF-001] Eq. 1):

  dx/dt = Ax + Sigma_j u_j(t) B^(j) x + Cu(t)

where B^(j) is the N x N modulatory connectivity matrix for the j-th
experimental condition, and u_j(t) is the modulatory input. The effective
connectivity becomes state- and input-dependent:

  A_eff(t) = A + Sigma_j u_j(t) B^(j)

B_j priors: B_free_j ~ N(0, B_PRIOR_VARIANCE) with B_PRIOR_VARIANCE = 1.0
(matching SPM12 one-state convention). Per-modulator binary masks enforce
sparsity. Diagonal elements of B_j default to zero (self-modulation
prohibited unless explicitly enabled).

Cite [REF-001] Eq. 1 for the bilinear equation.

**Section 1.7: Direct Observation Model**

For fitting DCM to neural-state trajectories (e.g., RNN hidden-state
dynamics or latent representations from neural data models), the
hemodynamic convolution is bypassed:

  y(t) = C_obs x(t) + epsilon

where C_obs is fixed at identity (I_N) for v0.6.0, making y directly
observe the latent neural states. This eliminates the balloon-Windkessel
model from the forward path, reducing ODE dimensionality from 5N to N.

The direct observation model uses a separate prior scale
(LC_A_PRIOR_VARIANCE = 1/16, vs 1/64 for BOLD-scale DCM) because
RNN/model latent states have different magnitude characteristics than
BOLD.

Multi-start SVI (>= 10 random restarts, selecting best ELBO) is standard
for this model due to the highly multimodal ELBO landscape.

Cite Phase 20 decisions and [REF-001].

**Section 6: DCM Interpretability for Neural Data Models (new top-level)**

The core v0.6.0 contribution: using DCM as an interpretability framework
for deep learning models trained on neural data.

6.1 CT-RNN Training: Continuous-time RNN (tau * dh/dt = -h + f(W_rec h +
W_in u + b)) trained on cognitive tasks via BPTT. Euler integration with
dt/tau discretization. Multiple seeds for ensemble analysis. Cite [REF-080].

6.2 Latent Extraction: PCA-based dimensionality reduction from H-dimensional
RNN hidden states to N-dimensional DCM state space. Output R-squared gate
(>= 0.90) verifies that reduced representations reconstruct behavioral
readout. Cite [REF-081].

6.3 Fixed-Point Analysis: Numerical fixed-point finding via gradient descent.
Jacobian computation at fixed points via torch.autograd.functional.jacobian.
Eigenvalue decomposition for linearization quality assessment. Stability
classification (stable/unstable/saddle). Cite [REF-081].

6.4 DCM Fitting Pipeline: Extract latent trajectories from trained model ->
PCA -> output R-squared gate -> fit bilinear DCM (direct observation model)
with multi-start SVI -> posterior A, B_j matrices with credible intervals.

6.5 Foundation Model Application: Same pipeline applied to pretrained brain
foundation models (TRIBE for fMRI, LaBraM/MEG-GPT for M/EEG). Latent
representations extracted and fit with DCM. Cite [REF-100], [REF-101].

**Section 7: Bayesian Model Reduction**

Analytic scoring of reduced DCM architectures from a single full-model fit
([REF-070]; Friston & Penny, 2011). Given full-model posterior
q(theta) = N(mu, Sigma) and reduced prior p_r(theta) = N(mu_r, Sigma_r),
the log model evidence for the reduced model is:

  ln p(y|m_r) approx ln p(y|m_f) + 1/2 [ln|Sigma_r^-1 Sigma| -
  (mu - mu_r)^T (Sigma_r^-1 - Sigma_0^-1)(mu - mu_r) -
  tr(Sigma_r^-1 Sigma - I)]

Circuit-size selection: fit full DCM, then analytically score all reduced
architectures (connection subsets). Validation against brute-force ELBO
comparison. Cite [REF-070], [REF-071].

**Section 8: Simulation-Based Inference for Spectral DCM**

Neural density estimation trained on simulated CSD from the spectral DCM
forward model. Amortized posterior inference via SNPE. Coverage calibration
via simulation-based calibration (SBC). Cite [REF-090], [REF-091],
[REF-043].

**Section 9: Hybrid VAE-DCM**

Sequential VAE where the decoder IS the DCM forward model. Encoder maps
observations to approximate posterior over DCM parameters (A, B_j, C) and
initial conditions. Training via ELBO maximization. Amortized inference
(single forward pass for new subjects). Cite [REF-110], [REF-001].
