  <action>
Create `scripts/generate_publication_figures.py` -- a modular figure
generation script for v0.6.0 publication figures. The script must:

1. Follow project conventions: `from __future__ import annotations`,
   NumPy-style docstring, ruff-compatible (88 char lines), type hints.

2. Import and use `_apply_style` from `benchmarks.plotting` for consistent
   publication-quality matplotlib styling (SciencePlots fallback chain).

3. Define one function per figure, each returning a `matplotlib.figure.Figure`.
   Each function takes a `results_dir: Path` argument pointing to where
   result artifacts (NPZ, JSON, CSV) from Phases 20-26 are stored.

4. Define the following figure functions. IMPORTANT: Each function must
   compute REAL figures from actual data files. If the result files do not
   exist yet (Phases 22-26 not complete), the function should raise
   FileNotFoundError with a clear message about which phase must complete
   first. Do NOT produce placeholder/dummy figures.

   a) `fig_pipeline_schematic(results_dir: Path) -> Figure`:
      Schematic diagram of the DCM interpretability pipeline:
      [Neural Data] -> [Train Model] -> [Extract Latents] -> [PCA] ->
      [Fit DCM] -> [Posterior A, B_j]
      This is a diagram figure using matplotlib patches, arrows, and text.
      No data files needed -- pure schematic. Use matplotlib.patches for
      rounded rectangles, FancyArrowPatch for directed arrows between stages.
      Color-code stages: blue for data processing, green for model training,
      orange for DCM inference. Add small annotations below each stage
      (e.g., "Cam-CAN MEG", "CT-RNN / Transformer", "PCA + R2 gate",
      "spDCM / bilinear DCM", "A, B_j + 95% CI").

   b) `fig_synthetic_recovery(results_dir: Path) -> Figure`:
      Parameter recovery on synthetic ground truth (Phase 20 results).
      2x2 subplot grid:
      - Top-left: True vs inferred A scatter (identity line reference)
      - Top-right: True vs inferred B scatter (identity line reference)
      - Bottom-left: A RMSE distribution across seeds (violin or strip)
      - Bottom-right: B RMSE distribution across seeds (violin or strip)
      Load data from `results_dir / "phase20_recovery.npz"` (expected keys:
      a_true, a_inferred, b_true, b_inferred, a_rmse_seeds, b_rmse_seeds).
      Raise FileNotFoundError if missing.

   c) `fig_connectivity_matrices(results_dir: Path) -> Figure`:
      DCM-derived effective connectivity from M/EEG model latents (Phase 22).
      1x3 subplot grid showing:
      - Left: Posterior mean A matrix (heatmap with diverging colormap,
        RdBu_r, centered at zero)
      - Center: Posterior uncertainty (std) A matrix (heatmap, sequential
        colormap)
      - Right: Significant connections (thresholded by 95% CI excluding
        zero, binary mask overlaid on mean)
      Load from `results_dir / "phase22_connectivity.npz"` (expected keys:
      a_mean, a_std, a_significant, region_names).
      Raise FileNotFoundError if missing.

   d) `fig_bmr_model_comparison(results_dir: Path) -> Figure`:
      BMR circuit selection results (Phase 23).
      Horizontal bar chart of log model evidence (relative to worst model)
      for all reduced architectures. Winning model highlighted in color.
      Comparison panel: BMR evidence vs brute-force ELBO (scatter with
      identity line).
      Load from `results_dir / "phase23_bmr.npz"` (expected keys:
      model_names, log_evidence, brute_force_elbo).
      Raise FileNotFoundError if missing.

   e) `fig_foundation_model_comparison(results_dir: Path) -> Figure`:
      Foundation model comparison across modalities (Phase 24).
      Grouped bar chart or matrix comparing DCM-derived connectivity
      metrics (e.g., mean |A|, connection density, agreement with known
      anatomy) across: fMRI foundation model (TRIBE), M/EEG foundation
      model, direct ROI fit (baseline).
      Load from `results_dir / "phase24_foundation.npz"` (expected keys:
      metrics, model_names, metric_names).
      Raise FileNotFoundError if missing.

   f) `fig_hybrid_vae_dcm(results_dir: Path) -> Figure`:
      Hybrid VAE-DCM results (Phase 25).
      2x1 subplot grid:
      - Top: Reconstruction loss curve (VAE ELBO over training epochs)
      - Bottom: Scatter of VAE-recovered A vs SVI-recovered A
        (agreement between hybrid and standalone DCM)
      Load from `results_dir / "phase25_vae_dcm.npz"`.
      Raise FileNotFoundError if missing.

   g) `fig_sbi_calibration(results_dir: Path) -> Figure`:
      SBI calibration for spectral DCM (Phase 26).
      2x1 subplot grid:
      - Top: SBC rank histogram (uniform = well calibrated)
      - Bottom: Coverage plot (expected vs observed CI coverage at
        multiple levels: 50%, 75%, 90%, 95%)
      Load from `results_dir / "phase26_sbi.npz"`.
      Raise FileNotFoundError if missing.

5. Define a `main()` function that:
   - Parses CLI args: `--results-dir` (default: `benchmarks/results`),
     `--output-dir` (default: `figures/`), `--figures` (comma-separated
     list of figure names, default: all), `--formats` (default: "png,pdf")
   - Calls each requested figure function, wrapping in try/except
     FileNotFoundError to print a skip message for figures whose
     upstream phase results are not yet available
   - Saves each figure to output_dir with descriptive filename
     (e.g., `pipeline_schematic.pdf`, `synthetic_recovery.png`)
   - Prints a summary of generated vs skipped figures

6. All figure functions should use these matplotlib conventions:
   - figsize appropriate for single-column (3.5 inch width) or
     double-column (7 inch width) journal format
   - Font size 8-10pt for axis labels, 6-8pt for tick labels
   - tight_layout() or constrained_layout=True
   - Colorbar labels where applicable
   - Panel labels (a, b, c, d) in top-left of each subplot

The pipeline schematic (fig_pipeline_schematic) should be fully
functional immediately since it requires no data files. All other figures
will raise FileNotFoundError until their upstream phases complete, which
is the correct behavior.
