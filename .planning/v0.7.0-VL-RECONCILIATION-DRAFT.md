## The problem

After the 2026-05-28 v0.6.0 consolidation, a substantial **Variational Laplace (VL)** inference
engine was implemented to match SPM12's `spm_nlsi_GN` and make VL (not SVI) the default DCM
inference. None of it is tracked in the roadmap. This milestone formalizes it.

## Current VL capability (`src/pyro_dcm/inference/`)

- `variational_laplace.py` — SPM12 `spm_nlsi_GN` engine: Gauss-Newton E-step, ReML M-step,
  SVD parameter reduction, adaptive regularization (`spm_dx`), 3-term free energy
  (L1 data fit + L2 parameter KL + L3 hyperprior). Returns a **full posterior covariance**.
- `forward_models.py` — `ForwardModel` protocol + `SpectralDCMForward` (CSD/hemo),
  `TaskDCMForward` (BOLD ODE), `LatentCircuitForward` (direct-obs bilinear).
- `csd_precision.py` — `compute_csd_precision` (`spm_dcm_csd_Q`).

**Validated:** `test_variational_laplace_recovery.py` (spectral), `test_vl_forward_model_protocol.py`
(protocol), `test_latent_circuit_vl.py` (latent-circuit). Latent-circuit VL closed **Phase 20-05**
(SYNTH-01/02/03; job 56268248/56270544): A-RMSE 0.026, B-RMSE 0.0048, pooled-R² 0.961, BMR
structure recovery 3/3.

## Proposed v0.7.0 phase structure (for /gsd:new-milestone to refine)

- **Phase A — VL engine consolidation & docs.** Move the VL code under a tracked phase; write the
  methods/REFERENCES entries (SPM12 `spm_nlsi_GN`, `spm_dcm_csd_Q`, ReML, `spm_svd`); retro-SUMMARYs
  for the 21.x commits. (Mostly documentation of done work.)
- **Phase B — VL validation matrix.** Systematic recovery + SPM12 cross-check across spectral /
  task / latent-circuit at multiple N, SNR; calibration (coverage from the full covariance).
- **Phase C — VL + BMR model comparison.** Standardize BMR-on-VL using the relative-evidence
  ranking + separation gap (the absolute prune threshold is broken by Laplace overconfidence —
  see todo `vl-overconfidence-for-bmr`). Possibly a posterior-tempering option.
- **Phase D — SBI reconciliation (optional).** Either fix SBC structurally (restrict prior to the
  stable region / reparameterize — see todo `sbi-sbc-calibration-gap`) or formally scope SBI as a
  speed-up benchmarked against the calibrated VL, not a primary inference path.
- **Phase E — real-data application** (depends on the parcellation fix landing + `[foundation]`).
