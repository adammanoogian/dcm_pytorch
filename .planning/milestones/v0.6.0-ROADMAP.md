# Milestone v0.6.0: Latent Circuit DCM (DCM Interpretability for Neural Data Models)

**Status:** ✅ SHIPPED 2026-06-10 (scope-cut)
**Phases:** 20-28 (8 planned phases + retroactive Phase 28 VL engine)
**Total Plans:** 34 (31 across Phases 20-27 + Phase 28 consolidation)

> **Scope-cut note (audited 2026-06-10).** Every plan executed, but a goal-backward audit
> (`milestones/v0.6.0-MILESTONE-AUDIT.md`) found the milestone's *real-data* scientific claims
> were not delivered — they were pivoted to synthetic or built-but-not-run (blocked on data
> access / compute). v0.6.0 ships its **delivered core**: a synthetic-validated DCM-recovery
> methodology + an SPM12-grade Variational Laplace inference engine + ready (un-run) real-data
> infrastructure. Real-data application is **deferred to v0.7.0** (deferred, not failed).

## Overview

v0.6.0 extends Pyro-DCM into a framework for DCM-based interpretability of deep-learning models
trained on neural data: synthetic validation (Phase 20), CT-RNN baseline (21), neural-data-model
interpretability pipeline (22), Bayesian Model Reduction (23), foundation-model use cases (24),
hybrid VAE-DCM (25), SBI for spectral DCM (26), publication artifacts (27). The inference that
actually delivered the milestone is the post-consolidation Variational Laplace engine,
consolidated here as Phase 28.

## Milestone Summary

**Key Decisions:**
- Switch DCM default inference SVI → Variational Laplace (full covariance / structured posterior;
  no AutoLowRankMVN/AutoIAF guide needed). Closed Phase 20-05's B-collapse that mean-field SVI
  could not.
- `C_obs` fixed at identity for v0.6.0 (rotation-ambiguity mitigation; learned C_obs → v0.7.0+).
- BMR structure selection uses *relative* evidence ranking (absolute ΔF pruning is broken by
  Laplace overconfidence — todo `vl-overconfidence-for-bmr`).
- Scope-cut at completion: synthetic methodology + engine ships; real-data application → v0.7.0.

**Issues Resolved:**
- Phase 20-05 B-RMSE collapse (SVI ~0.31 → VL 0.0048); R² "failure" was a variance-pooling
  metric bug; ELBO-across-N model selection replaced by BMR.
- HVAE-02 sign recovery: `sign(0)` metric artifact → `masked_sign_recovery` (confirmed 0.7745).
- Parcellation No-Placeholders violation removed (real nilearn `vol_to_surf`).

**Issues Deferred (→ v0.7.0):**
- Real Cam-CAN M/EEG application (Phase 22 gates 1-2).
- Real foundation-model execution + cross-modal comparison (Phase 24).
- SBI SBC structural calibration + real-M/EEG demo (Phase 26).
- VL posterior tempering for absolute BMR; parcellation nilearn runtime validation.

**Technical Debt / Infra:**
- **Mutagen `models/` ignore** silently excludes `src/pyro_dcm/models/` from M3 sync (todo
  `mutagen-models-ignore`) — fix before v0.7.0 M3 runs touching that package.
- v0.6.0 had no standalone REQUIREMENTS.md section (requirements lived as ROADMAP success
  criteria); REQUIREMENTS.md still holds pending v0.3.0 RECOV items (Phase 16.1 unexecuted).
